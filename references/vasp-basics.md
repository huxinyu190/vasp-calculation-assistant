# VASP 基础理论速查（写给小白）

这份文档用最直白的话讲清楚 VASP 计算是怎么回事。你不需要理解背后的量子力学，只需要知道每个文件是干嘛的、几个关键参数怎么选。

## 一、VASP 在算什么

VASP 用**第一性原理（DFT，密度泛函理论）**计算材料的性质。它不需要任何实验数据，只根据原子种类和位置，求解量子力学方程，得到：

- 体系的总能量
- 原子的受力（用于结构优化）
- 电子结构（能带、态密度）
- 磁性、电荷密度等

一句话：**你给它"原子怎么摆"，它告诉你"能量是多少、稳不稳定、力往哪推"**。

## 二、四大输入文件

一次 VASP 计算，核心是 4 个输入文件。它们互相配合，缺一不可。

### 1. POSCAR —— 结构文件（原子怎么摆）

描述晶胞：晶格矢量、原子种类、原子位置。

```
Si 结构示例                ← 第1行：注释（随便写）
5.43                       ← 第2行：晶格缩放因子
0.0 0.5 0.5                ← 第3-5行：三条晶格矢量（Å）
0.5 0.0 0.5
0.5 0.5 0.0
Si                         ← 第6行：元素符号
2                          ← 第7行：每个元素的原子数
Direct                     ← 第8行：坐标类型（Direct=分数坐标 / Cartesian=笛卡尔）
0.00 0.00 0.00             ← 第9行起：原子坐标
0.25 0.25 0.25
```

关键点：
- **晶格矢量和原子坐标至少 7 位有效数字**，否则对称性分析不准。
- `Direct` 是分数坐标（0~1 之间），`Cartesian` 是笛卡尔坐标（Å）。
- 如果某行坐标后带 `T T T` 或 `F F F`，那是 Selective Dynamics（选择性固定原子）。

### 2. POTCAR —— 赝势文件（用什么"势"描述原子）

描述每种元素的赝势（把芯电子"打包"，只算价电子，大幅加速）。

关键点：
- **元素顺序必须和 POSCAR 完全一致**！这是新手最容易犯的致命错误。
- 里面有个 `ENMAX` 值（截断能建议值），INCAR 的 ENCUT 必须 ≥ 它。
- 多元素时用 `cat` 按 POSCAR 顺序拼接。
- 赝势来源：官方推荐库（PBE/LDA 等），可从 Materials Project 或官方渠道获取。

### 3. KPOINTS —— k 点采样（布里渊区怎么切）

决定在倒空间取多少个采样点做积分。

```
自动网格示例              ← 第1行：注释
0                         ← 第2行：0=自动生成
Monkhorst-Pack            ← 第3行：生成方法
4 4 4                     ← 第4行：k 点网格（4×4×4）
0 0 0                     ← 第5行：偏移量
```

经验规则：
- **金属**：k 点要密（8×8×8 或更高）
- **半导体/绝缘体**：中等（4×4×4 左右）
- **大超胞**：可以疏（2×2×2 甚至 Γ 点）
- 做能带计算时用"线模式"（沿高对称路径）

### 4. INCAR —— 参数文件（怎么算）

控制计算类型、收敛标准、泛函等，是最复杂的文件。核心参数：

| 参数 | 作用 | 常用取值 |
|------|------|---------|
| ENCUT | 平面波截断能 | ≥ ENMAX 的 1.3~1.5 倍 |
| ISMEAR | 电子展宽方法 | 0=高斯（半导体/绝缘体）、1=MP（金属）、-5=四面体（DOS/能带） |
| SIGMA | 展宽宽度 | 一般 0.05~0.2 eV |
| EDIFF | 电子步收敛标准 | 1E-5 ~ 1E-6 |
| EDIFFG | 离子步收敛标准 | 负值=按力收敛（如 -0.01 eV/Å） |
| IBRION | 离子优化算法 | -1=不动（单点）、1=RMM-DIIS、2=CG（推荐）、3=阻尼MD |
| ISIF | 优化自由度 | 2=只动原子、3=全优化（原子+晶胞+体积） |
| NSW | 最大离子步数 | 50~200 |
| NELM | 最大电子步数 | 60~200 |
| ALGO | 电子步算法 | Normal（默认）/ Fast / All |

## 三、标准计算流程

一次完整的材料计算，通常按这个顺序：

```
1. 结构优化（relaxation）：ISIF=3, IBRION=2, ISMEAR=0/1
   → 让原子和晶胞找到能量最低点，得到 CONTCAR
2. 自洽计算（SCF）：用 CONTCAR 当 POSCAR，更严的 EDIFF
   → 得到精确的电荷密度、波函数
3. 性质计算：
   - 态密度 DOS：加密 k 点，ISMEAR=-5
   - 能带：高对称路径 k 点，ISMEAR=-5
   - 弹性、声子等
4. 收敛性测试：逐步加密 ENCUT 和 k 点，直到目标量变化 < 阈值
```

**收敛性测试是最容易漏、却最重要的一步**：不做的后果是结果不可靠。

### 收敛性测试具体怎么做（小白版步骤）

目的：确认 ENCUT 和 k 点已经"够密"，再加密也不会让结果明显变化。

**ENCUT 收敛测试**（先固定 k 点，只变 ENCUT）：
1. 固定 k 点网格（如 8×8×8），ENCUT 从 ENMAX 的 1.2 倍开始
2. 每次 ENCUT 增加 50~100 eV（如 400 → 480 → 560 → 640）
3. 记录每次的总能量，算相邻两次的能量差 ΔE
4. 当 ΔE < 1 meV/原子（0.001 eV/原子）时，取上一个 ENCUT 为收敛值

**k 点收敛测试**（再用收敛的 ENCUT，只变 k 点）：
1. 固定 ENCUT，k 点从 2×2×2 开始逐步加密（4×4×4 → 6×6×6 → 8×8×8 → 10×10×10）
2. 记录每次总能量，算 ΔE
3. 当 ΔE < 1 meV/原子时，k 点即收敛

**判定标准**：能量变化 < 1 meV/原子（0.001 eV/原子）即视为收敛。对带隙、磁矩等量，也可用其变化量 < 0.01 eV 作为判据。

## 四、最常见错误（避坑清单）

1. **POTCAR 元素顺序和 POSCAR 不一致** → 直接报错或算错体系
2. **ENCUT 太低**（< ENMAX）→ 结果不准确
3. **ISMEAR 选错**（绝缘体用金属展宽）→ 能量不准
4. **POSCAR 精度不够**（少于 7 位）→ 对称性判断错误
5. **k 点太疏** → 能量不收敛、带隙不准
6. **收敛标准太松** → 结果不可靠
7. **改了一个文件却忘了检查其他文件的一致性**
