# 输入文件校验清单（核心）

这是整个 Skill 的**重中之重**。任何输入文件只要被改动过，就必须完整重新执行本清单的校验。校验的目标是：**在 VASP 真正跑起来之前，把所有能提前发现的错误都抓出来**。

校验分三层：**格式层 → 一致性层 → 物理合理性层**。逐层往下查，任何一层不过都要修复后再继续。

## 铁律

- **文件动过必重查**：哪怕只改了一个数字，也要走完整校验。
- **结论要分级**：明确标注「通过 / 警告 / 错误」，警告可以继续但需用户知情，错误必须修复。
- **拿不准就联网查证**：结构可对照 Materials Project（https://materialsproject.org/）/ ICSD（https://icsd.products.fiz-karlsruhe.de/），参数可对照 VASP 官方 wiki（https://www.vasp.at/wiki/）。完整网址清单见 `online-resources.md`。

## 第一层：格式校验

### POSCAR
- [ ] 第 2 行缩放因子是合法数字（不能是 0）
- [ ] 第 3-5 行三条晶格矢量，每条 3 个数字，且线性无关（行列式 ≠ 0）
- [ ] 元素符号行与原子数行元素个数一致
- [ ] 原子数总和 = 后面实际列出的坐标行数
- [ ] 坐标类型是 `Direct` 或 `Cartesian`（大小写不敏感）
- [ ] 每条坐标 3 个数字
- [ ] 晶格矢量、原子坐标精度 ≥ 7 位有效数字（否则警告）
- [ ] 如有 Selective Dynamics，每个原子后有 3 个 T/F 标记

### POTCAR
- [ ] 文件非空，能读到赝势头信息
- [ ] 能提取出每个元素的 ENMAX、价电子数、元素符号
- [ ] 元素符号列表与 POSCAR 完全一致（顺序 + 种类）

### KPOINTS
- [ ] 第 2 行是 0（自动网格）或正整数
- [ ] 第 3 行方法名合法（Monkhorst-Pack / Gamma / Line-mode）
- [ ] 网格三个数都是正整数（自动网格时）
- [ ] 线模式时，高对称点坐标格式正确

### INCAR
- [ ] 每行格式 `TAG = VALUE`（= 号两侧有空格）
- [ ] 没有拼写错误的参数名（对照官方参数表，可用 `--dry-run` 或联网查证）
- [ ] 没有重复定义同一个参数（后定义会覆盖前定义，易误）

## 第二层：一致性校验（最关键）

这四个文件不是独立的，必须互相匹配：

| 检查项 | 规则 | 不满足的后果 |
|--------|------|-------------|
| **元素顺序** | POSCAR 元素顺序 == POTCAR 元素顺序 | 直接算错体系 / 报错 |
| **ENCUT vs ENMAX** | INCAR.ENCUT ≥ max(POTCAR.ENMAX)，建议 ≥ 1.3 倍 | 结果不准 |
| **k 点密度 vs 晶胞** | 大晶胞可疏、小晶胞要密；金属要密、绝缘体可疏 | 能量不收敛 |
| **ISMEAR vs 体系** | 绝缘体/半导体用 0，金属用 1，DOS/能带用 -5 | 能量不准 |
| **ISMEAR vs k 点** | k 点很疏时 ISMEAR 不能设太小（展宽要能覆盖） | 不收敛 |
| **ISIF/IBRION 匹配** | ISIF=3 必须配 IBRION=1/2/3（不能 -1）；单点算 IBRION=-1 | 参数冲突 |
| **SIGMA 合理性** | 一般 0.05~0.2 eV，过大或过小警告 | 能量偏差 |
| **EDIFFG 符号** | 负值=按力收敛，正值=按能量收敛，要符合计算意图 | 收敛判据错 |

## 第三层：物理合理性校验

- [ ] 原子间距是否过近（< 0.5 Å 通常说明结构有重叠错误，警告）
- [ ] 晶胞体积是否合理（和元素种类、原子数匹配，异常小/大需警告）
- [ ] 计算类型（单点/优化/DOS/能带）与 INCAR 参数组合是否自洽
- [ ] 收敛标准（EDIFF/EDIFFG）是否与计算目的匹配，具体数值判据：
  - 结构优化：EDIFF = 1E-4 ~ 1E-5，EDIFFG = -0.02 ~ -0.01（按力收敛）
  - 精确能量（SCF/DOS/能带）：EDIFF = 1E-6 或更严
  - EDIFFG 为负值时按力收敛（eV/Å），正值时按能量收敛（eV），符号必须符合计算意图
- [ ] 是否需要收敛性测试但还没做（提醒用户）

## 校验方式

1. **脚本自动校验**：运行 `scripts/validate_inputs.py <目录>`，自动执行格式层 + 一致性层的机械检查，输出 PASS/WARN/ERROR 列表。
2. **人工+联网核验**：对脚本查不出的物理合理性、结构真实性、参数最佳实践，用 WebSearch/WebFetch 对照 Materials Project（https://materialsproject.org/）、ICSD（https://icsd.products.fiz-karlsruhe.de/）、VASP 官方 wiki（https://www.vasp.at/wiki/）核对。具体网址清单见 `online-resources.md`。**注意：如果目标网页抓取不到（如 VASP wiki 反爬返回 403），必须停下来让用户手动查找，给出精确网址和详细查找步骤，拿到用户反馈后再继续，绝不猜。**
3. **dry-run 验证**（可选，若环境可用）：`vasp_std --dry-run` 能让 VASP 自己解析一遍输入，暴露脚本查不出的隐藏错误，同时给出 NBANDS/NKPTS 供并行参数优化。

## 校验输出格式

校验完成后，输出一份清单：

```
[PASS] POSCAR 晶格矢量线性无关
[PASS] POTCAR 元素顺序与 POSCAR 一致
[WARN] POSCAR 原子坐标仅 5 位有效数字，建议 ≥ 7 位
[ERROR] INCAR.ENCUT=350 低于 POTCAR ENMAX=400
```

- **ERROR 必须修复**后才能进入下一步。
- **WARN 要让用户知情**，是否处理由用户决定。
- 修复后**重新跑一遍完整校验**，不能只查改过的那一项。

## 常见错误 → 修复对照

| 症状 | 原因 | 修复 |
|------|------|------|
| 报错元素不匹配 | POTCAR 顺序错 | 按 POSCAR 顺序重排 POTCAR |
| 能量异常高/低 | ENCUT 低于 ENMAX | 提高 ENCUT |
| 金属体系能量抖动 | ISMEAR 用 0 | 改 ISMEAR=1 |
| 绝缘体带隙偏小 | ISMEAR 用 1 | 改 ISMEAR=0 |
| 优化不收敛 | IBRION 不合适 / POTIM 太大 | 换 IBRION=2，降 POTIM |
| 改了一个文件后算错 | 没检查一致性 | 重新完整校验 |
