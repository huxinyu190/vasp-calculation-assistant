# 预计算策略

预计算（试算）是正式计算前的"快速彩排"：把体系/参数**缩小**，跑一次特别快的计算，从这次的过程和结果中，提前判断正式计算的大致走向，并反哺优化输入文件和耗时估算。

## 一、预计算做什么

一句话：**用最少的时间，拿到最大信息量**。具体目标是回答这几个问题：
1. 正式计算大概会得到什么样的结果（趋势、量级）？
2. 结果是否符合用户预期？
3. 正式计算大概要多久（实测单步耗时）？
4. 输入文件有没有隐藏问题（会提前暴露）？

## 二、怎么缩小计算（降级参数）

预计算要"特别快"，通过降低精度/规模实现：

| 手段 | 预计算 | 正式计算 | 说明 |
|------|--------|---------|------|
| ENCUT | 降到 ENMAX 的 1.0~1.1 倍 | 1.3~1.5 倍 | 减少平面波数 |
| k 点 | 减半或降到 Γ 点 | 收敛后的网格 | 减少采样点 |
| EDIFF | 放宽到 1E-3~1E-4 | 1E-5~1E-6 | 少跑电子步 |
| NSW | 5~10 步 | 50~200 | 只试算几步 |
| 结构优化 | 只动原子（ISIF=2） | 视需求 ISIF=3 | 减少自由度 |

**原则**：预计算参数要能代表正式计算的**物理本质**（同样的体系、同样的计算类型），只是精度和规模降低。不要缩到物理上失真（比如 k 点降到连基本趋势都看不出来）。

## 三、从预计算结果提取什么信息

1. **能量趋势**：能量是否在下降、收敛速度如何 → 判断正式计算能否收敛、大致收敛到多少。
2. **受力大小**：初始力多大 → 判断结构离平衡点多远、需要多少离子步。
3. **单步耗时**：从 OSZICAR 实测每个电子步/离子步耗时 → 反哺耗时估算（能力 3）。
4. **收敛稳定性**：SCF 是否顺利、有无发散迹象 → 提前暴露 INCAR 参数问题（如 ISMEAR 选错、AMIX 需调）。
5. **物理合理性**：能量量级、键长、磁性是否符合常识 → 提前发现 POSCAR/POTCAR 问题。

## 四、预计算 → 反哺优化（反馈环）

预计算的结果不是终点，要拿回去改：

```
预计算 → 发现 ISMEAR 不收敛 → 改 INCAR → 重新校验（能力2）
预计算 → 实测单步耗时 → 校准正式耗时估算（能力3）
预计算 → 能量趋势异常 → 检查 POSCAR 结构是否合理 → 联网核对（结构对照 Materials Project/ICSD，网址见 `online-resources.md`）
预计算 → 初始力巨大 → 增加 NSW、调整 IBRION/POTIM
```

**"初始力巨大"的量化判定**（避免含糊）：
- 最大初始力 > 1.0 eV/Å → 结构离平衡很远，正式优化可能需很多步（NSW 设 200+，用 IBRION=2 稳健算法，POTIM 降到 0.3~0.5）
- 最大初始力 0.1~1.0 eV/Å → 正常范围，NSW 设 100 左右即可
- 最大初始力 < 0.1 eV/Å → 结构已接近平衡，很快收敛

**铁律**：预计算后如果改了任何输入文件，必须重新走完整校验（能力 2）。

## 五、预计算输出格式

```
[预计算结论]
- 实际耗时：X 秒
- 能量趋势：从 -12.34 eV 降至 -12.31 eV，正常下降，预计可收敛
- 初始最大力：0.5 eV/Å，结构离平衡较近
- 单电子步实测耗时：Y 秒 → 正式计算预计 Z 小时
- 是否符合同户预期：是（能量量级符合 Si 体系）
- 发现的问题：无 / 有（列出）
- 建议：ENCUT 建议提高到 1.3 倍 ENMAX；NSW 建议设为 100
```

## 六、边界

- 预计算只能给**趋势和量级**，不能代替正式计算得出最终精确结果。
- 若预计算发现**根本性问题**（如结构错误、赝势不匹配），应停止，先修复，而不是继续正式计算。
- 预计算结果要诚实标注是"试算/推断"，正式结果以正式计算为准。
