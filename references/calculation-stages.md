# VASP 八个计算阶段：要什么、怎么设、验收什么

> 这份文档回答「这条阶段链里每一步具体在干什么」。要哪些阶段由需求决定（见 `intake.md` 第六节）；参数为什么这么取，见 `vasp-basics.md`；文件写完的校验见 `input-validation.md`。

## 一、能力边界

本流程覆盖 **8 个计算阶段**，全部是 LDA/GGA（可含 +U）、CPU 纯 MPI、单节点：

| 阶段 | 目录惯例 | 得到什么 | 典型用途 |
|---|---|---|---|
| relax | `01-relax` | 平衡几何、总能、力与应力 | 体相、表面、吸附、缺陷的初始结构 |
| static | `02-static` | 高精度总能、SCF 电荷密度、费米能 | 能量比较（形成能、吸附能、相稳定性） |
| dos | `03-dos` | 总 DOS、分波 PDOS、积分电子数 | 电子结构、d 带中心、成键分析 |
| band | `04-band` | 沿高对称路径的本征值 | 带隙、直接/间接跃迁、有效质量 |
| workfunction | `05-workfunction` | LOCPOT、真空能级、功函数 | 表面与二维材料功函数 |
| charge_density | `06-charge_density` | CHGCAR、AECCAR0/2 | Bader 电荷、差分电荷密度 |
| frequency | `07-frequency` | Γ 点振动频率与模式 | 驻点性质、ZPE、热力学校正 |
| aimd | `08-aimd` | 固定晶胞 NVT 轨迹 | 热稳定性、扩散、熔融、结构演化 |

阶段编号不要求全跑，只跑目标需要的。

### 不在流程内的能力

VASP 本身能做，但需要单独准备输入与验收方案，**不能套用现有阶段**：

hybrid（HSE06 等）、meta-GGA（r2SCAN 等）、DFPT 声子与声子色散、NEB / CI-NEB、NpT 系综、SOC 与非共线、光学介电函数与吸收谱、GW / BSE、多节点与 GPU。

遇到这类需求：先说明方法与验收口径，再单独设计，不伪装成标准阶段。

## 二、每个阶段开始前都要有的信息

不管跑哪个阶段，这几项缺一项就不要开始：

1. **结构**：POSCAR / CIF / XYZ，含真实晶格、原子坐标、元素顺序；是否保留 Selective dynamics；来源（实验 CIF、数据库、自建、已优化结果）
2. **体系类型**：体相 / 表面 slab / 二维层 / 孤立分子 / 缺陷或掺杂超胞——决定 k 网格、真空层、偶极修正、固定层
3. **磁性**：非磁 / FM / AFM；哪些原子向上向下；初始磁矩；是否要在计算中保持磁序
4. **电荷与组分**：是否带电、缺陷电荷态；掺杂浓度、空位与间隙位
5. **方法偏好**：泛函；+U 的元素与 U 值；色散；是否 SOC
6. **精度与比较目标**：要哪个物理量；精度要求（meV、eV/Å、cm⁻¹）；是否要与实验或文献可比
7. **资源**：核数上限、单作业时限、机时预算

## 三、分阶段详解

### 3.1 relax：几何优化

**得到什么**：平衡结构、总能、残余力与应力。

**需要用户提供**：初始结构；固定哪些原子（表面通常固定底部几层）；是否允许变胞；力收敛标准。

**关键参数**

- `IBRION=1/2/3`、`NSW>0`、`EDIFFG`
- **`EDIFFG` 为负是力阈值（eV/Å），为正才是能量阈值（eV）**——这一条最常被写反
- `ISIF=2` 只放松原子；`ISIF=3` 同时改晶胞；表面与二维通常不能用 `ISIF=3`

**注意事项**

- 初始磁矩必须显式给出
- `ISYM` 可能把磁构型“优化”回高对称态
- Pulay 应力与变胞精度要一起看
- 不要为了让作业早点停而放宽 `EDIFFG`
- 跑满 `NSW` 不等于收敛

**后处理**：核验 CONTCAR 的残余力、应力、键长配位、磁矩、晶胞。科学验收后，把 CONTCAR **复制**到 static 目录当 POSCAR，不要移动。

### 3.2 static：静态单点

**得到什么**：固定几何下的高精度总能、SCF 电荷密度、费米能；按需同时产出 CHGCAR、AECCAR0/2、LOCPOT。

**需要用户提供**：已验收的几何；与后续计算一致的泛函、赝势、+U、色散、磁序；需要的输出。

**关键参数**

- `IBRION=-1`、`NSW=0`、`ICHARG=2`（重新自洽）
- `LCHARG=T` → CHGCAR；`LAECHG=T` → AECCAR0/2；`LVHAR=T` → LOCPOT
- `LWAVE` 按是否需要重启决定
- 含 +U 的 d/f 元素**在这里**就设 `LMAXMIX=4/6`，否则下游全部无效

**注意事项**

- 一次 SCF 能同时产出 DOS/band/Bader/功函数所需的密度与势，不必为每个后处理重做 SCF
- 能量比较必须统一：泛函、赝势、`ENCUT`、k 点、展宽、+U、自旋
- 回执里的总能是最后一次 TOTEN（含展宽熵的自由能），不是无熵能；做能量差时要说清用哪种定义
- 单点之后仍要看力和应力，判断几何是否真的到位

**后处理**：记录总能、费米能、磁矩；保存 CHGCAR 及其来源信息。

### 3.3 dos：态密度

**得到什么**：总态密度、分波投影态密度、积分电子数。

**需要用户提供**：已收敛的 SCF 结构与方法；足够密的均匀 k 网格；是否需要分波投影；能量范围与展宽。

**关键参数**

- `IBRION=-1`、`NSW=0`、`LORBIT=11`、`NEDOS>1`
- 自洽 DOS：`ICHARG=2`；固定密度：`ICHARG=11` + 兼容的 CHGCAR 与来源记录
- `NBANDS` 要覆盖分析能量范围

**注意事项**

- 不能用能带线模式算 DOS
- `ISMEAR=-5`（四面体）需要足够多的 k 点；单 Γ 点的分子或薄层不能照搬
- 金属与绝缘体的展宽选择不同
- +U 的 `LMAXMIX` 必须在源 SCF 就设好

**后处理**：先核对 DOSCAR 表头与列定义；总 DOS、自旋分辨、分波投影；积分电子数与总价电子数核对；d 带中心等描述符。**记录费米能来源**，不同阶段或不同计算的费米能不能混用。

### 3.4 band：能带

**得到什么**：沿高对称路径的本征值、带隙、直接/间接跃迁信息。

**需要用户提供**：均匀网格 SCF 的 CHGCAR；按**实际晶胞**设计的高对称路径（每段起终点成对）。

**关键参数**

- `IBRION=-1`、`NSW=0`、`ICHARG=11`
- Line-mode KPOINTS
- `NBANDS` 覆盖所需空带

**注意事项**

- 路径必须与该 POSCAR 的倒空间匹配
- 固定密度 +U 的能带要求源 SCF 已保存足够的 `LMAXMIX`（d=4，f=6）
- 杂化泛函不能用 `ICHARG=11` 套用
- 孤立分子不要算“晶体能带”

**后处理**：检查实际 k 点、路径分段与标签、自旋、带数；VBM/CBM 与带隙从路径读取；**费米能要对齐均匀网格 SCF**，不能用路径采样自己产生的费米能盲目对齐；判断直接/间接，必要时算有效质量。

### 3.5 workfunction：功函数

**得到什么**：静电势 LOCPOT、真空能级、功函数。

**需要用户提供**：已验收的表面或二维结构；真空方向与厚度；面内 k 网格；是否偶极修正。

**关键参数**

- `IBRION=-1`、`NSW=0`、自洽
- `LVHAR=T`、`LVTOT=F`
- 不对称 slab 按实际电荷分布决定 `LDIPOL / IDIPOL / DIPOL`

**注意事项**

- 真空一般 ≥15 Å，并检查势平台是否平坦
- 两侧真空分别报告
- 半导体表面的费米能选择要说明

**后处理**：对 LOCPOT 做平面平均；取真空能级 `E_vac`；用**同一次计算**的 `E_F` 算 `Φ = E_vac − E_F`（eV）。没有可靠平台就不给该侧数值。

### 3.6 charge_density：电荷密度

**得到什么**：CHGCAR、AECCAR0/2，用于 Bader 与差分电荷。

**需要用户提供**：已验收结构；`LCHARG=T`、`LAECHG=T`；足够细的 FFT 网格；差分电荷还需要各参考态的同晶胞同网格输入。

**关键参数**

- `IBRION=-1`、`NSW=0`、自洽
- `LCHARG=T`、`LAECHG=T`
- 必要时显式设 `NGXF / NGYF / NGZF`

**注意事项**

- 差分电荷的各参考态必须同盒子、同实空间网格、同方法
- 原子位置与参考态定义要写清楚
- Bader 通常用 AECCAR0 + AECCAR2 作分盆参考，对 CHGCAR 积分
- 不要把 AECCAR0 与 AECCAR2 之和叫“自旋密度”

**后处理**：核对积分总电子数与赝势 `ZVAL`、原子顺序、真空电荷；Bader 净电荷（说明是 ZVAL 减盆电子数，还是相反约定）；差分电荷图；平面平均电荷转移。

### 3.7 frequency：有限差分频率

**得到什么**：Γ 点振动频率与模式，作为驻点性质、ZPE 与热力学校正的原料。

**需要用户提供**：已优化的驻点结构；全体系还是部分自由度；是否需要 ZPE 或热力学量。

**关键参数**

- 全体系：`IBRION=6`，利用对称性
- 部分 Hessian：`IBRION=5` + Selective dynamics
- `NFREE=2/4`；`POTIM=0.015 Å`（位移幅度）；较紧的 `EDIFF`（如 1E-7）

**注意事项**

- 频率计算的 `POTIM` 是**位移幅度（Å）**，不是 MD 时间步——同名不同义，写错就是灾难
- 部分 Hessian 里选择性标记对应**笛卡尔分量**，与优化时“放松/固定”的语义不同
- 不允许全部分量固定
- 虚频要结合体系判断：极小值应无虚频，过渡态应恰好一个
- 平移模应接近零
- 这不是声子色散；声子色散要超胞/Phonopy 或 DFPT，另行准备

**后处理**：检查 3N 个模式（部分 Hessian 按活动笛卡尔分量计数）；频率有限、编号连续；振型归属；虚频标记与解释；`ZPE = ½Σhν`，热力学校正要写明温度与统计公式，虚频怎么处理也要写明。

### 3.8 aimd：固定晶胞 NVT

**得到什么**：固定晶胞下的 NVT 轨迹，用于热稳定性、扩散、熔融和结构演化。

**需要用户提供**：初始结构（或上一段完整 CONTCAR）；目标温度或温度程序；时间步；总步数或总时长；采样间隔；随机种子策略。

**关键参数**

- `IBRION=0`、`MDALGO=2`、`ISIF=2`、`SMASS>=0`
- `NSW × POTIM` 为总时长（`POTIM` 单位 fs）
- `TEBEG / TEEND` 温度；`NBLOCK` 采样间隔

**注意事项**

- 时间步按体系最快振动选，常见 0.5~2 fs
- 总时长要覆盖平衡段 + 采样段
- 同一初态 + 同一种子不是独立统计样本
- 重启要复制完整 CONTCAR，并保留速度与预测校正信息
- 温度与能量“看起来稳定”不等于已经平衡
- 恒温轨迹不以总能量严格守恒作为唯一判据

**后处理**：先丢掉平衡段；温度分布、结构稳定性；RDF、MSD 与扩散系数、配位数、氢键统计；速度自相关谱。自由能要增强采样，另行设计。

## 四、标准流程

1. **定问题与模型**：明确目标物理量；明确体系边界（真空、固定层、电荷态）
2. **建立初始结构**：来源可追溯；元素顺序与后续 POTCAR 一致；表面与二维留足真空；分子放在足够大的盒子里
3. **确定方法**：泛函、赝势、`ENCUT`、k 网格、展宽、+U、色散、自旋、SOC；**所有用于能量比较的计算保持同一套设置**
4. **建阶段目录**：每阶段一个全新目录（`体系/01-relax`、`体系/02-static`）；上游产物**复制**进来，不移动
5. **准备四个输入**：四个文件齐全且非空；`ISTART / ICHARG` 显式填写；重启文件必须是独立副本，不能软链接或硬链接；固定密度要有来源记录
6. **提交前只读检查**：元素顺序、`ENCUT`、k 点、展宽、磁矩、`LMAXMIX`、输出开关、并行参数
7. **资源与并行**：单节点、纯 MPI、`OMP_NUM_THREADS=1`；`NCORE/NPAR` 与 `KPAR` 的乘积必须整除 MPI 进程数；不同时设 `NCORE` 和 `NPAR`
8. **提交并查状态**：提交后查一次；之后只在关键节点查，不高频轮询
9. **三层验收**：调度状态（是否正常结束）→ 数值收敛（电子步、离子步、产物非空、数值有限）→ 科学可用性（几何、磁态、路径、采样、参考态是否合理）
10. **后处理**：在新目录做；保留原始 OUTCAR、OSZICAR、DOSCAR、EIGENVAL、CHGCAR；不覆盖上游结果
11. **失败处理**：保留原目录与证据；换新目录修正重跑；不自动改参，不原地删锁或删输出后重跑

典型链路：

```text
relax → static → dos / band / workfunction / charge_density
              ↘ frequency（在合适的驻点结构上单独做）
              ↘ aimd（单独设计采样方案）
```

## 五、跨阶段常见风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 可比性不足 | 不同 `ENCUT`、k 点、展宽、赝势版本、+U、色散、自旋下的能量不能直接相减 | 统一方法并记录 |
| 赝势不一致 | 元素顺序、版本、泛函不匹配 | 按 POSCAR 顺序拼接，核对 `VRHFIN`、`ZVAL`、`ENMAX` |
| 磁态漂移 | 初始磁矩不足，AFM 构型被对称性抹平 | 显式设磁矩，检查优化后的磁矩分布 |
| 表面与二维模型不当 | 真空不足、偶极未修正、固定层不合理 | 真空 ≥15~20 Å，按需偶极修正，明确固定层 |
| 带电体系未修正 | 缺背景电荷或偶极修正 | 明确电荷态并做相应修正 |
| +U 的 `LMAXMIX` 缺失 | 下游补设无效 | 在产生 CHGCAR 的源 SCF 设（d=4，f=6） |
| 并行布局不整除 | `KPAR`、`NCORE` 与进程数不匹配 | 提交前检查整除关系 |
| 重启文件用错 | 软链接、硬链接或来源不明的 CHGCAR | 独立复制并记录来源，显式设 `ISTART / ICHARG` |
| 把“完成”当“算对” | 退出码 0、文件存在、进程数正确都不等于结果有效 | 分别报告调度状态、数值收敛、科学可用性 |

## 六、后处理对照表

| 原始文件 | 提取内容 | 常见后处理 |
|---|---|---|
| OUTCAR / OSZICAR | 总能、力、应力、磁矩、费米能、频率、MD 温度 | 收敛与稳定性检查 |
| CONTCAR | 优化后几何 | 键长、配位、晶胞核验；作为下一阶段 POSCAR |
| DOSCAR | 总 DOS、PDOS、积分电子数 | 画 DOS、d 带中心、自旋分辨 |
| EIGENVAL / PROCAR | 本征值、k 点、投影 | 能带图、带隙、有效质量 |
| LOCPOT | 平面平均静电势 | 真空能级、功函数 |
| CHGCAR / AECCAR0/2 | 电荷密度、全电子密度 | Bader、差分电荷、平面平均 |
| XDATCAR / REPORT | 轨迹、温度、能量 | RDF、MSD、扩散系数、配位统计 |
| vasprun.xml | 结构化汇总 | 统一解析能量、频率、轨迹 |

解析前务必核对文件头与列定义（DOSCAR 表头、EIGENVAL 的 k 点与带数、XDATCAR 帧头与帧数），**不要写死行号**。画图时记录费米能来源、能量零点与单位。

## 七、提交前检查清单

**结构与模型**

- [ ] POSCAR 晶格、坐标、元素顺序正确
- [ ] 表面与二维真空层足够
- [ ] 固定层与选择性动力学设置合理
- [ ] 分子盒子足够大，避免周期性镜像作用

**磁性**

- [ ] 初始磁矩已显式设置
- [ ] FM/AFM 构型明确
- [ ] 对称性设置不会破坏目标磁序

**方法**

- [ ] 泛函、赝势版本一致
- [ ] `ENCUT` 满足精度要求
- [ ] k 网格与体系维度匹配
- [ ] 展宽适合金属或绝缘体
- [ ] +U 的 U 值与 `LMAXMIX` 正确
- [ ] 色散修正按需启用

**输入文件**

- [ ] 四个文件均存在且非空
- [ ] `ISTART / ICHARG` 显式填写
- [ ] 重启文件为独立副本
- [ ] 固定密度有来源记录
- [ ] 输出开关与后续阶段需求一致

**并行与资源**

- [ ] MPI 进程数与节点容量匹配
- [ ] `OMP_NUM_THREADS=1`
- [ ] `NCORE/NPAR` 与 `KPAR` 整除
- [ ] 未同时设 `NCORE` 与 `NPAR`
- [ ] 作业时限已按规模估算

**验收**

- [ ] 调度状态正常
- [ ] 电子步与离子步收敛证据充分
- [ ] 关键产物非空且数值有限
- [ ] 几何、磁态、路径、采样、参考态已复核
- [ ] 未把“运行完成”直接当作科学结论

## 八、单位与常用约定

| 物理量 | 单位 | 说明 |
|---|---|---|
| 能量 | eV | 总能、吸附能、形成能 |
| 力 | eV/Å | `EDIFFG` 为负时使用 |
| 位移 | Å | 频率计算的 `POTIM` |
| 时间步 | fs | AIMD 的 `POTIM` |
| 温度 | K | `TEBEG / TEEND` |
| 频率 | THz / cm⁻¹ | 振动模式 |
| 晶格与坐标 | Å | POSCAR 的 Cartesian 坐标 |
| 电荷 | e | Bader 与积分电子数 |

**能量定义**：`TOTEN` 是含展宽熵贡献的自由能；做能量差时要说明用自由能还是无熵能；不同展宽、不同 k 点下的能量不可直接比较。赝势 `ZVAL` 决定价电子数，是 Bader 积分与电子数核对的基准。
