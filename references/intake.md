# 需求采集：生成输入文件之前先问清楚

> 这份文档管的是「问」——用户说完“帮我算个带隙”之后，先确认什么、问到什么程度才可以动手。
> 阶段链和每个阶段的关键参数见 `calculation-stages.md`；文件写完之后对不对，见 `input-validation.md`。

## 一、为什么必须有这一步

用户一句话就能提出一个需要几十小时机时的计算。这句话背后至少有四件事没定：算哪个物理量、什么模型、什么方法、什么精度。不确认就生成，通常错在这三处：

| 真实事故 | 后果 | 本来该问的问题 |
|---|---|---|
| 用户要“带隙”，直接按 PBE 出了结果，投稿时被要求与实验比 | PBE 低估带隙 30~50%，整条链要重算 | 精度要求是与实验可比，还是趋势正确即可 |
| 用户说“算个吸附能”，没定参考态 | 能量差算出来了，但减的是不同盒子、不同 k 点的总能 | 参考态是什么，三个体系是否同晶胞同网格 |
| 体系含 Ni，没问磁性，默认非磁跑完 | 能量看着正常，磁态根本不对，结论全废 | 磁性状态与初始磁矩 |

这三类错误的共同点：**VASP 不会报错**。它只会安静地算完，给你一个自洽、收敛、但物理上无意义的结果。所以确认环节不是流程上的客套，是唯一能拦住它们的地方。

这也是本 Skill 的铁律：**关键物理不猜，确认后才生成**。

## 二、分级门禁：什么时候精简、什么时候完整

不是每次都要走完六个阶段。算个 Si 单点能，问十几个问题和直接问三句，结果质量没差别——但用户的耐心有差别。

| 判定 | 档位 |
|---|---|
| 单点能、能量差（体相）、DOS、能带；体系非磁或磁序明确、中性、无缺陷、无吸附 | **精简档** |
| 含 3d/4f 过渡金属或稀土、需要 AFM 构型、带电体系、缺陷/掺杂、吸附、表面/二维/界面、功函数、频率、AIMD、投稿级定量对比 | **完整档** |
| 用户说“先看看”“帮我理一下思路”“这个能不能算” | 完整档，但**只讨论不生成** |

三条判定原则：

1. **条件项一触发就升级**。磁性、电荷态、缺陷、吸附、表面这几项里只要有一项需要展开，说明这个任务的物理模型不平凡，直接走完整档。
2. **拿不准就走完整档**。多问三句的代价，远小于生成一份错的输入再跑十几个小时。
3. **档位只管问多少，不管松紧**。精简档也不允许静默默认磁性、电荷态、+U、色散、SOC——这五项在两档里都必须有明确值。

## 三、引导原则

### 3.1 结果导向

从“你要回答什么科学问题、需要哪个物理量”出发倒推阶段链和参数。不要一上来就问 ENCUT 和 k 点——用户答不上来，而且顺序反了。

### 3.2 最小充分

只问**答案会改变方案**的问题。已经能从结构文件读出来的（元素、原子数、晶胞、有无 Selective dynamics）不要问；能按体系类型合理默认的，给推荐值请用户确认，而不是开放提问。

### 3.3 一问一答

- 每轮 1~3 个高度相关的问题，优先 1 个
- 优先给选项，推荐项放第一位并标注“推荐”
- 每个问题说明“为什么问”和“会影响什么”
- 不要一次抛出十几项的问卷

### 3.4 先读后问

用户给了结构文件，先解析再开口：元素种类与顺序、原子数与晶胞参数、维度（真空方向、层状）、是否已有 Selective dynamics、像不像已优化的结构。解析结果用来减少提问，并在确认单里复核。

解析用 `scripts/fetch_structure.py --from <文件>`，它会打印结构摘要。

### 3.5 关键物理不猜

以下八项必须有用户的明确回答，或用户明确授权按建议默认。不能静默选择，也不能用“一般来说都是这样”带过：

磁性 / 电荷态 / +U 的元素与 U 值 / 色散修正 / SOC / 泛函（尤其是否用杂化或 meta）/ 能量比较的参考态 / 表面与二维的真空厚度和偶极修正。

确认单里前五项合并成一行「关键物理」，后三项各自独立成栏（泛函、能量参考态、真空层与偶极修正）——加起来仍然是八项，一项都不能空着。

### 3.6 分段复述

每完成一个主题（目标、体系、模型、方法、资源），用 2~4 行复述关键结论请用户纠正。不要攒到最后一次性汇总——那时候改起来代价大。

### 3.7 默认值要标注性质

经验默认值只能写成“建议起点，需要按体系验证”，不能写成“已收敛”“标准参数”“标准答案”。用户明确指定的值优先于默认值。

### 3.8 超范围先说明

杂化泛函、meta-GGA、NEB、DFPT 声子与声子色散、NpT、SOC 与非共线、光学介电函数、GW/BSE、GPU、多节点——这些 VASP 能做，但不在本流程范围内：

1. 明确告知不在固定流程内
2. 说明需要单独准备输入与验收方案
3. 问用户是改用范围内方案，还是另行准备
4. 不擅自套用现有阶段，不伪装成标准流程

## 四、对话流程

```text
阶段 A  开场与目标        → 要回答什么、要哪些结果、什么精度
阶段 B  体系与结构        → 什么维度、结构从哪来、要不要扩胞
阶段 C  物理模型          → 磁性、电荷、缺陷/掺杂、吸附
阶段 D  方法与精度        → 泛函、赝势、+U、色散、SOC
阶段 E  参数与收敛        → ENCUT、k 点、展宽、收敛判据
阶段 F  计算链与资源      → 哪几个阶段、多少核、多久
阶段 G  确认单（硬门禁）  → 用户书面确认后，才生成输入文件
```

每个阶段结束做一次简短复述。阶段 G 是硬门禁：没确认不进入生成。

**第一轮不要问参数**，先建立目标和边界：

> 我可以帮你生成 VASP 输入文件。开始前确认三件事：
> 1. 你想回答的科学问题是什么？
> 2. 最终需要哪些结果（结构、能量、带隙、DOS、功函数、电荷分析、频率、AIMD）？
> 3. 有没有结构文件？是否需要和实验或文献定量对比？

用户只给了模糊目标（“算一下这个材料”），先追问 A1、A2，不要自己假设。

## 五、问题库

编号用于内部追踪和确认单引用。“必问条件”说明什么时候不能跳过。

### 5.1 A 组：目标与交付

| ID | 问题 | 选项 / 需要的信息 | 为什么问 | 必问条件 |
|---|---|---|---|---|
| A1 | 要回答的科学问题是什么？ | 开放回答 | 决定阶段链和验收标准 | 总是 |
| A2 | 最终需要哪些结果？ | 多选：平衡结构 / 总能与能量差 / 带隙与能带 / DOS 与 PDOS / 功函数 / Bader 与差分电荷 / 频率与 ZPE / AIMD 轨迹 | 直接映射到阶段链 | 总是 |
| A3 | 精度要求是什么？ | 定性趋势 / 定量（给数值）/ 与实验或文献可比 | 决定 ENCUT、k 点、展宽、是否杂化 | 总是 |
| A4 | 有对比基准吗？ | 实验值 / 文献计算值 / 已有结果 / 无 | 决定方法可比性 | 有定量要求时 |
| A5 | 交付形式是什么？ | 仅输入文件 / 输入加运行 / 输入加后处理脚本 / 完整报告 | 决定生成范围 | 总是 |
| A6 | 时间与精度怎么取舍？ | 尽快出结果 / 平衡 / 高精度优先 | 影响资源和收敛策略 | 有时限或预算时 |

**追问规则**

- A2 选“能量差” → 必须追问参考态（E6）
- A2 选“带隙” → 必须追问是否与实验对比；PBE 会低估带隙，要求定量对比就说明杂化超出流程
- A2 选“AIMD” → 必须追问温度、时长、统计目标

### 5.2 B 组：体系与结构

| ID | 问题 | 选项 / 需要的信息 | 为什么问 | 必问条件 |
|---|---|---|---|---|
| B1 | 体系类型和维度？ | 体相 / 表面 slab / 二维层 / 一维 / 孤立分子 / 缺陷或掺杂超胞 / 界面 | 决定 k 网格、真空、固定层、偶极修正 | 总是 |
| B2 | 有结构文件吗？来源？ | POSCAR/CIF/XYZ；实验 CIF / 数据库 / 自建 / 已优化 / 需要建模 | 决定是否建模与结构可靠性 | 总是 |
| B3 | 要扩胞吗？ | 倍数或目标原子数 | 影响成本、缺陷浓度、k 点 | 缺陷、掺杂、吸附、界面 |
| B4 | 哪个晶面、多少层、固定几层？ | 指数、层数、固定层数 | 决定 slab 模型与成本 | B1 为表面或界面 |
| B5 | 真空多厚？要偶极修正吗？ | 厚度（Å）；开/关 | 影响功函数、吸附能、2D 电子结构 | B1 为表面、二维、界面 |
| B6 | 缺陷/掺杂的类型、位点和浓度？ | 空位/间隙/取代；位点；浓度或超胞 | 决定模型与电荷态 | 涉及缺陷或掺杂 |
| B7 | 吸附物、位点、覆盖度？ | 分子、取向、top/bridge/hollow、覆盖度 | 决定初始结构与能量参考 | 涉及吸附 |
| B8 | 允许晶胞变化吗？ | 固定晶胞 / 只放松原子 / 同时变胞 | 决定 `ISIF` | 体相、界面、应变体系 |
| B9 | 有应变、约束或特殊边界条件吗？ | 应变大小与方向；固定原子 | 影响应力与自由度 | 有明确要求时 |

**处理规则**

- 用户给了结构文件，先解析并复述元素、原子数、晶胞、真空方向，请他确认；不要重复问这些
- 结构来源不明或明显未优化 → 建议先 relax，或把 relax 加进阶段链
- 表面/二维没给真空厚度 → 给建议值（≥15 Å，二维可到 20 Å）并请确认，不静默采用

### 5.3 C 组：物理模型

| ID | 问题 | 选项 / 需要的信息 | 为什么问 | 必问条件 |
|---|---|---|---|---|
| C1 | 磁性状态是什么？ | 非磁 / 铁磁 / 反铁磁 / 不确定 | 决定是否自旋极化与初始磁矩 | 含过渡金属、稀土、O₂、自由基 |
| C2 | 初始磁矩怎么设？ | 各元素初始磁矩（μB）；或由我给建议 | 决定能否收敛到目标磁态 | C1 非“非磁” |
| C3 | AFM 的具体构型？ | 哪些原子自旋向上/向下；层间还是子晶格 | AFM 结果对构型敏感 | C1 为反铁磁 |
| C4 | 体系带电吗？ | 中性 / 带电（几 e）；缺陷电荷态 | 需要背景电荷与修正，能量不可比 | 缺陷、掺杂、离子吸附 |
| C5 | 要保持磁序或特殊约束吗？ | 是（说明）/ 否 | 防止优化后磁性漂移 | 磁性体系 |
| C6 | 涉及强关联电子吗？ | 是（元素与 U 值）/ 否 / 不确定 | 决定是否 +U 与 `LMAXMIX` | 含 3d/4f、部分氧化物 |

**处理规则**

- 用户答“不确定” → 说明不同选择的影响，给推荐并请他确认，不要自己选
- 不要擅自给 +U；U 值必须来自用户指定或明确文献
- 磁性体系必须提醒：优化后要回看磁矩和磁序，不能只看能量

| ID | 问题 | 选项 / 需要的信息 | 为什么问 | 必问条件 |
|---|---|---|---|---|
| D1 | 用什么泛函？ | PBE（默认）/ PBEsol / 其他 GGA / HSE 等杂化 | 决定全部能量与带隙 | 总是 |
| D2 | 赝势用哪套？ | PBE 标准 / 用户指定版本 / 按元素选 | 决定价电子与可比性 | 总是 |
| D3 | 用 +U 吗？ | 是（元素、U 值、d/f）/ 否 | 修正强关联体系 | C6 为“是”或不确定 |
| D4 | 加色散修正吗？ | D3(BJ) / optB86b-vdW / 无 | 影响吸附能、层间结合、分子晶体 | 表面吸附、二维、分子晶体 |
| D5 | 需要 SOC 吗？ | 是 / 否 | 影响重元素能带与磁性 | 含重元素、拓扑、自旋轨道效应 |
| D6 | 需要杂化或 meta-GGA 吗？ | 是 / 否 | 超出固定流程，需另行准备 | A3 要求定量带隙时 |

**处理规则**

- D1 选杂化或 D6 为“是” → 明确告知不在固定流程内，需单独准备 SCF、能带与验收方案
- D5 为“是” → 需要非共线计算（`vasp_ncl`），同样超出流程
- 色散、+U、SOC 一旦定下，必须写进确认单，不能中途静默改

| ID | 问题 | 选项 / 需要的信息 | 为什么问 | 必问条件 |
|---|---|---|---|---|

| E6 | 能量参考态是什么？ | 体相 / 分子 / 干净表面；具体化学势 | 决定能量差是否有意义 | 形成能、吸附能、相稳定性 |

**处理规则**

- E6 最容易被跳过：吸附能、形成能没有明确参考态和化学势，数值就没有意义
- E7 为“是”且含 +U → 必须在**产生 CHGCAR 的源 SCF** 就设 `LMAXMIX`（d=4，f=6），下游补设无效
- 收敛测试是额外计算，要说明增加的成本并单独确认

## 六、任务类型 → 阶段链与必问项

| 用户目标 | 任务短名 | 建议阶段链 | 关键验收点 |
|---|---|---|---|
| 只要平衡结构 | `relax` | relax | 残余力、应力、CONTCAR 合理性 |
| 能量差 / 形成能 / 相稳定性 | `energy` | relax → static | 统一方法、参考态、化学势 |
| DOS / PDOS | `dos` | relax → static → dos | k 密度、费米能来源、积分电子数 |
| 带隙 / 能带 | `band` | relax → static → band | 高对称路径、VBM/CBM、费米能对齐 |
| 功函数 | `workfunction` | relax → static（workfunction） | 真空平台、偶极修正、同次费米能 |
| Bader / 差分电荷 | `charge` | relax → static（charge_density） | FFT 网格、ZVAL、参考态一致 |
| 频率 / ZPE | `frequency` | relax → frequency | 3N 模式、虚频、位移幅度 |
| AIMD | `aimd` | 初态或 relax → aimd | 温度、时长、平衡段、采样 |
| 多个目标 | `combo` | 合并共享 SCF 再分叉 | 每个阶段独立验收 |

**组合原则**

- 同一次静态 SCF 可同时产出 CHGCAR、AECCAR、LOCPOT，不为每个后处理重复做 SCF
- 能带必须由均匀网格 SCF 提供 CHGCAR，不能用路径采样自己的费米能对齐
- 频率和 AIMD 成本高，单独确认时长与资源

各阶段要什么输入、关键参数、注意事项与后处理验收点，见 `calculation-stages.md`。

## 七、默认值的边界

以下只是**建议起点**，不是收敛证明。用户明确指定的值优先。

| 项目 | 建议起点 | 不能默认的情况 |
|---|---|---|
| 泛函 | PBE | 用户要求杂化/meta；强关联体系；定量带隙对比 |
| 赝势 | PBE 标准赝势 | 用户指定版本；元素在库中缺失 |
| ENCUT | 约 1.3 × 最大 ENMAX | 用户指定；要做收敛测试；软硬元素混合 |
| k 网格 | 体相约 0.02~0.03 Å⁻¹ 间距；表面面内加密、真空方向 1；分子单 Γ | 金属、磁性、DOS、能带要更密；用户指定 |
| 展宽 | 金属 Methfessel-Paxton；绝缘体 Gaussian 或四面体 | 半导体带隙、高精度 DOS；四面体 k 点不足 |
| EDIFF | 1E-6 eV | 频率等需要更紧；用户指定 |
| EDIFFG | -0.02 eV/Å | 软物质、大体系可放宽；用户指定 |
| 真空层 | ≥15 Å，二维可到 20 Å | 功函数、偶极体系要更厚并做收敛 |
| LMAXMIX | +U 时 d=4、f=6 | 不含 +U；未在源 SCF 设置则下游无效 |
| 频率 | `IBRION=6`、`NFREE=2`、`POTIM=0.015 Å` | 部分 Hessian 用 `IBRION=5`；用户指定位移 |
| AIMD | `POTIM` 0.5~1 fs、NVT、固定晶胞 | 用户指定温度、时长、系综；NpT 超范围 |
| 并行 | 单节点、纯 MPI、`OMP_NUM_THREADS=1` | 用户给出核数；多节点超范围 |

**用法**：把默认值写进确认单的「采用的默认值」一栏，并注明“建议起点，待验证”。不要写“已收敛”“标准参数”。

## 八、确认单：生成与校验

确认单是这次需求的唯一凭据，也是门禁的检查对象。用 `scripts/intake.py` 生成和校验。

```bash
# 看有哪些任务类型、档位怎么选
python scripts/intake.py --list

# 生成骨架（任务类型：relax/energy/dos/band/workfunction/charge/frequency/aimd/combo）
python scripts/intake.py --new energy --level simple -o intake.md

# 填完后校验
python scripts/intake.py --check intake.md
```

**退出码**：`0` 通过，可以生成；`2` 用法或文件错误；`3` 门禁阻断，禁止生成。

### 8.1 两个档位的差别

| | 精简档 | 完整档 |
|---|---|---|
| 字段数 | 17 | 43 |
| 适用 | 单点、能量、DOS、能带，且无磁性/电荷/缺陷/吸附/表面 | 其余全部 |
| 必填 | 科学问题、目标结果、精度要求、体系类型、结构来源、关键物理、泛函、ENCUT、k 网格、展宽、阶段链、核数、单作业时限、采用的默认值 | 再加上交付物、赝势、EDIFF、EDIFFG、收敛测试、固定密度复用、节点数、需要验证的项目 |

功函数、电荷、频率、AIMD、组合任务没有精简档——它们的物理模型本来就不平凡，脚本会自动改用完整档。

### 8.2 三类必填是怎么来的

1. **必填**：档位规则决定的固定项，见上表。
2. **本任务固有**：任务类型自带。`energy` 必须给能量参考态；`workfunction` 必须给真空层、偶极修正、晶面层数固定层；`frequency` 必须给频率设置；`aimd` 必须给温度与时长。
3. **条件项**：从已填内容推出来的，共 11 条触发规则——

| 已填内容触发 | 追加必填 |
|---|---|
| 关键物理里磁性不是“非磁” | 初始磁矩 |
| 磁性是反铁磁 / AFM | 反铁磁构型 |
| `+U=是` | U 值与元素 |
| 体系类型含表面 / 二维 / 界面 / slab | 真空层、偶极修正 |
| 体系类型含表面 / 界面 / slab | 晶面、层数与固定层 |
| 体系类型含缺陷 / 掺杂 / 空位 / 取代 / 间隙 | 缺陷或掺杂设置 |
| 体系类型或目标结果含吸附 | 吸附物与位点 |
| 目标结果含能量差 / 形成能 / 吸附能 / 相稳定 | 能量参考态 |
| 目标结果含 AIMD | AIMD 温度与时长 |
| 目标结果含频率 / ZPE | 频率设置 |
| 目标结果含差分电荷 | 能量参考态 |

精简档的确认单里没有这些条件栏位。一旦某个条件被触发，脚本会报「缺栏位」并提示改用完整档——**这就是该升级的信号**，别硬凑。

### 8.3 关键物理那一行怎么写

固定五个键，缺一个就阻断：

```markdown
- 关键物理（必填）：磁性=反铁磁（Ni 自旋向上）；电荷态=中性；+U=是（Ni 3d，U=6.2）；色散=无；SOC=否
```

`磁性` 写“不确定”会被判为**未定**——不确定时必须给推荐方案并拿到用户点头，不能把不确定带进生成阶段。

### 8.4 检查结果怎么读

| 标记 | 含义 | 处理 |
|---|---|---|
| `[未填]` | 栏位在，值是空的或还是 `待填` | 补值，或按 8.2 的条件规则确认它是否真的需要 |
| `[缺栏位]` | 栏位整个不存在 | 加一行「- 键：」，或按提示重新生成完整档 |
| `[未定]` | 写了“不确定”“知道了”这类没有决定的值 | 给方案让用户选，拿到明确答复 |
| `提醒` | 不阻断但要说出来 | 例如默认值写成了“已收敛”、阶段链和任务对不上 |

## 九、追问与异常处理

**回答“不知道 / 你决定”**：不要跳过。给推荐方案和影响，请他确认——「这项会影响 X。我建议 A（理由），代价是 Y；改用 B 会影响 Z。你接受 A 吗？」

**回答模糊**（“算准一点”“差不多就行”）：追问到可量化的一档——「“准一点”是指与实验值比较（需要杂化或更高精度），还是趋势正确即可（PBE 足够）？」

**需求冲突**（“高精度”+“一小时内出结果”）：明确指出不能同时满足，给两种方案及代价，请用户选。不自行牺牲精度或时限。

**超出固定流程**：按 3.8 处理——说明范围、给替代方案、请用户选。

**结构文件缺失或异常**：缺失就请他提供或确认是否建模；格式错就说明具体问题；元素顺序不清就请他确认；明显未优化就建议先 relax。

**赝势元素缺失**：生成前核对结构元素在授权赝势库里是否齐全。缺了就停下报告，不换其他来源，不编造 POTCAR。

**用户要求跳过确认**：说明理由——「生成前需要你确认这份需求单，尤其是磁性、电荷态和方法，否则输入可能不符合你的模型。确认后我立即生成。」

**用户只想“先看看”**：只讨论方案，不生成文件，明确说“确认后我再生成”。

## 十、生成前门禁

以下全部满足才能进入生成：

- [ ] 用户已明确确认需求单（写了“确认生成”这类话）
- [ ] `intake.py --check` 返回 0
- [ ] 结构可解析，元素顺序与原子数已确认
- [ ] 赝势库中所需元素齐全
- [ ] 目标结果与阶段链一一对应
- [ ] 超范围需求已说明，并排除或另行处理
- [ ] 参考态（吸附能、形成能）已明确
- [ ] 假设与风险已写进确认单
- [ ] 用户知道“生成输入”不等于“提交作业”

任一项不满足：继续追问，不生成。

## 十一、生成后的交付说明

生成完成后按这五条说清楚，不要只说“已经生成了”：

1. **生成了什么**：阶段目录、四个输入文件、提交脚本
2. **关键参数**：泛函、赝势、ENCUT、k 网格、展宽、磁性、+U、色散
3. **采用的假设**：哪些是建议默认值、为什么
4. **需要验证的项目**：收敛性、磁态、真空厚度、参考态
5. **下一步**：怎么检查输入、要不要提交、提交需另行授权

不要在交付说明里写“已收敛”“结果可靠”——这些要由实际计算和后处理验证。

## 十二、两个完整示例

### 示例 1：单层 MoS₂ 带隙

**用户**：帮我算 MoS₂ 的带隙。

**Agent**：先确认三点：单层还是体相？有结构文件吗？需要和实验值定量对比吗？

**用户**：单层，有 POSCAR，想和实验比。

**Agent**：单层 MoS₂ 用 PBE 通常低估带隙（常见 1.6~1.8 eV，实验约 1.9 eV）。要和实验定量比就得用杂化，那不在固定流程内，要单独准备。你的选择：

1. PBE 看趋势（推荐，流程内，成本低）
2. 杂化方案（另行准备，成本高）

**用户**：先用 PBE 看趋势。

**Agent**：好。再确认：单层是非磁吧？真空用 15 Å 还是更厚？要不要 SOC（影响价带分裂）？

**用户**：非磁，真空 20 Å，不要 SOC。

**Agent**：阶段链建议 `relax → static → band`：static 用均匀网格并保留 CHGCAR，band 用线模式。资源上单作业多少核、时限多久？

**用户**：64 核，2 小时。

**Agent**：确认单已填好（要点：PBE，真空 20 Å，非磁、中性、无 +U、无色散、无 SOC，k 网格面内 12×12、真空方向 1，ENCUT 520，`EDIFF=1E-6`）。请核对第 3、4 节，确认后我生成输入。

（这一步之所以能走精简档：非磁、中性、无缺陷、体系是二维但真空和偶极已明确，条件项没有额外触发。）

### 示例 2：Pt(111) 上 CO 吸附能

**用户**：算 Pt(111) 上 CO 的吸附能。

**Agent**：先定模型：slab 几层、底部固定几层？CO 覆盖度和吸附位点是什么？考虑色散吗（CO 在 Pt 上通常要）？

**用户**：4 层，底部 2 层固定，1/4 覆盖，top 位，加 D3。

**Agent**：吸附能还得明确参考态：CO 气相能量用多大盒子、自旋怎么处理？另外 slab 上下对称吗？不对称建议加偶极修正。

**用户**：CO 用 15 Å 盒子，自旋极化，slab 不对称，加偶极修正。

**Agent**：阶段链 `relax（干净 slab）→ relax（CO/Pt）→ static（吸附体系 + 干净 slab + CO 气相）`，三者必须同晶胞、同网格、同方法。确认核数和时限后我生成。

**这里必须走完整档**：体系含表面（触发晶面/真空/偶极）、含吸附（触发吸附物与位点）、目标是吸附能（触发能量参考态）、Pt 是过渡金属（磁性必须明确回答）。
