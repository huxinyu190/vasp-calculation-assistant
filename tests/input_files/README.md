# VASP 计算验证测试套件

这是一套用于**验证 VASP 安装是否正确、各计算模块是否正常工作**的测试输入文件。

## 设计目标

1. **速度快**：每个测试都是最小体系（1~2 个原子），在普通台式机上**单个测试几秒到 1 分钟**内完成，8 个测试合计 **5 分钟内**能全部跑完。
2. **可对照**：每个测试都附有**来自公开资料（VASP 官方教程 / 官方 workshop 材料 / 同行评议文献）的参考值**，跑完后对比即可判断 VASP 计算是否正确。
3. **覆盖全**：8 个测试覆盖 VASP 最核心的计算模块——单点能、结构优化、自旋极化（磁性）、多元素体系、态密度（DOS）、能带结构。

## 目录结构

```
tests/input_files/
├── 01_si_single_point/   单点能（最基础，先跑这个）
├── 02_si_relax/          结构优化（晶格常数）
├── 03_fe_magnetic/       铁磁 bcc Fe（自旋极化）
├── 04_ni_magnetic/       铁磁 fcc Ni（自旋极化）
├── 05_mgo_relax/         多元素离子晶体 MgO 结构优化
├── 06_nacl_relax/        多元素离子晶体 NaCl 结构优化
├── 07_dos/               态密度 DOS（依赖 01 的 CHGCAR）
└── 08_bands/             能带结构（依赖 01 的 CHGCAR）
```

## 运行前的准备（重要）

每个测试目录里都有 `INCAR`、`POSCAR`、`KPOINTS` 三个文件，但 **`POTCAR` 需要你自己准备**（它是 VASP 许可保护的专有文件，无法也**不应**公开分发）。

每个目录下的 `POTCAR.README` 文件会告诉你该目录需要哪个元素的赝势、以及如何拼接。通用做法：

```bash
# 假设你的赝势库在 ~/potpaw_PBE
cd tests/input_files/01_si_single_point
cat ~/potpaw_PBE/Si/POTCAR > POTCAR

# 多元素体系（如 MgO），顺序必须与 POSCAR 的元素顺序一致
cd tests/input_files/05_mgo_relax
cat ~/potpaw_PBE/Mg/POTCAR ~/potpaw_PBE/O/POTCAR > POTCAR
```

> **推荐使用 PAW_PBE 系列赝势**，本文档所有参考值都是基于 PBE 泛函给出的。

## 运行方式

在每个测试目录里，准备好 POTCAR 后执行：

```bash
mpirun -np 4 vasp_std > vasp.log 2>&1
```

（单机少核即可，这些体系很小，4 核完全足够）

## 各测试详解与公开参考值

### 测试 01：Si 单点能（最基础的冒烟测试）

- **验证模块**：VASP 核心自洽场（SCF）求解器、基础运行链路
- **体系**：金刚石结构 Si，2 原子基胞，晶格常数 5.43 Å
- **关键参数**：ENCUT=300 eV，4×4×4 Gamma 网格，PBE 泛函
- **公开参考值**（Kitchin 教程实测）：总能量 **-10.835370 eV**，每原子 **-5.417685 eV/atom**
- **判读**：你的计算结果每原子能量应落在 **-5.42 ± 0.05 eV/atom** 范围内。误差超过这个范围（尤其是数量级不对）说明赝势选错、结构写错或 VASP 编译有问题。
- **耗时**：几秒

### 测试 02：Si 结构优化（晶格常数）

- **验证模块**：离子弛豫（IBRION=2）+ 变胞（ISIF=3）模块
- **体系**：金刚石结构 Si，1 原子原胞，初始晶格常数 5.43 Å
- **关键参数**：ENCUT=240 eV，8×8×8，ISIF=3（同时优化晶格矢量）
- **公开参考值**：PBE 计算的平衡晶格常数 **≈5.47 Å**（VASP 官方教程与 AM05 文献均给出 PBE 约 5.47 Å，实验值 5.430 Å）
- **判读**：优化后的晶格常数应落在 **5.45~5.48 Å** 之间。PBE 泛函普遍比实验值略高 ~1%，这是**正常的、已知的系统性误差**，不是计算错误。
- **耗时**：几十秒

### 测试 03：铁磁 bcc Fe（自旋极化）

- **验证模块**：自旋极化计算（ISPIN=2）、磁性体系
- **体系**：体心立方 Fe，1 原子晶胞，晶格常数 2.83 Å
- **关键参数**：ENCUT=320 eV，8×8×8 Monkhorst-Pack，ISPIN=2，MAGMOM=1*4
- **公开参考值**：PBE 磁矩 **2.19~2.20 μB/atom**（实验值 2.22 μB），平衡晶格常数 2.832 Å
- **判读**：OUTCAR 中 `number of electron ... magnetization` 一行的总磁矩应约 **2.2 μB**。如果磁矩接近 0，说明自旋极化没生效（漏了 ISPIN=2）或初始 MAGMOM 设置不对。
- **耗时**：几秒

### 测试 04：铁磁 fcc Ni（自旋极化）

- **验证模块**：自旋极化 + 较小磁矩体系的灵敏度
- **体系**：面心立方 Ni，1 原子晶胞，晶格常数 3.52 Å
- **关键参数**：ENCUT=320 eV，8×8×8，ISPIN=2，MAGMOM=1*3
- **公开参考值**：PBE 磁矩 **0.63 μB/atom**（实验值 0.55~0.57 μB），体积 10.90 Å³/atom
- **判读**：Ni 的磁矩较小（~0.6 μB），是对磁矩灵敏度更好的测试。结果应落在 **0.5~0.7 μB** 之间。
- **耗时**：几秒

### 测试 05：MgO 结构优化（多元素离子晶体）

- **验证模块**：多元素体系 + 结构优化
- **体系**：岩盐结构 MgO，2 原子原胞（Mg + O），初始晶格常数 4.21 Å
- **关键参数**：ENCUT=400 eV，6×6×6，ISIF=3
- **公开参考值**：PBE 平衡晶格常数 **4.168 Å**（实验值 4.207 Å）
- **判读**：优化后晶格常数应落在 **4.15~4.19 Å** 之间。这个测试同时验证了「多元素 POTCAR 拼接顺序正确」——如果 Mg/O 顺序写反，会得到完全错误的结果。
- **耗时**：几十秒

### 测试 06：NaCl 结构优化（多元素离子晶体）

- **验证模块**：多元素体系 + 结构优化（与 05 互补，验证不同元素组合）
- **体系**：岩盐结构 NaCl，2 原子原胞（Na + Cl），初始晶格常数 5.64 Å
- **关键参数**：ENCUT=400 eV，6×6×6，ISIF=3
- **公开参考值**：PBE 平衡晶格常数 **5.702 Å**（实验值 5.595 Å）
- **判读**：优化后晶格常数应落在 **5.68~5.72 Å** 之间。
- **耗时**：几十秒

### 测试 07：Si 态密度 DOS

- **验证模块**：非自洽 DOS 计算（ICHARG=11 读电荷密度 + ISMEAR=-5 四面体法）
- **依赖**：需要先跑测试 01，把它的 `CHGCAR` 复制到本目录
- **关键参数**：ENCUT=300 eV，11×11×11（加密 k 点），ICHARG=11，ISMEAR=-5
- **公开参考值**：Si 的 PBE 带隙约 **0.6 eV**（VASP 官方 workshop 材料明确给出 Si 实验带隙 1.2 eV、PBE 理论值 0.6 eV）
- **判读**：从 DOSCAR 中费米能级处的态密度应为 0（半导体），且价带顶到导带底的带隙约 **0.5~0.7 eV**。如果带隙为 0（金属性），说明 DOS 计算设置有误。
- **耗时**：几十秒

### 测试 08：Si 能带结构

- **验证模块**：能带计算（沿高对称路径 L-Γ-X-U 的非自洽计算）
- **依赖**：需要先跑测试 01，把它的 `CHGCAR` 复制到本目录
- **关键参数**：ENCUT=300 eV，Line-mode KPOINTS（沿 L-Γ-X-U），ICHARG=11
- **公开参考值**：Si 是**间接带隙半导体**，导带底在 X 点附近，价带顶在 Γ 点，PBE 间接带隙约 0.6 eV
- **判读**：从 EIGENVAL 中应看到：Γ 点价带顶能量高于 X 点附近导带底，形成约 0.6 eV 的间接带隙。能带形状应与 Si 的标准能带图一致。
- **耗时**：几十秒

## 验证结论如何判断

- **全部 8 个测试都落在合格范围内** → VASP 安装正确、各模块正常工作，可以放心开始正式计算。
- **某个测试偏差较大** → 定位到具体模块（单点能/优化/磁性/DOS/能带），检查对应的 INCAR 参数或 POTCAR。
- **所有测试都偏差、或能量数量级都不对** → 大概率是 VASP 编译问题、赝势库路径错误、或 POTCAR 整体选错，先查环境。

## 重要说明

1. **PBE 泛函的系统性误差是正常的**：晶格常数普遍比实验值高 ~1%、带隙普遍比实验值低（Si 实验 1.2 eV vs PBE 0.6 eV），这些是已知现象，**不是计算错误**。判读时不要拿实验值直接对比，要拿「PBE 参考值」对比。
2. **所有参考值均来自公开资料**：Si 单点能来自 Kitchin 教授的 VASP 教程；晶格常数来自 VASP 官方 tutorial 与 AM05 文献；Fe/Ni 磁矩来自 diva-portal 博士论文与 USTC 论文；MgO/NaCl 晶格常数来自 AM05 文献；Si 带隙来自 VASP 官方 workshop 材料。
3. **POTCAR 必须自备**：本套件不包含任何 POTCAR 文件，因为它受 VASP 许可保护。请用你自己的正版赝势库。
