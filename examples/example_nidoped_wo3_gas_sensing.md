## 一、案例背景与科学问题

### 1.1 你在研究什么

你在做 **Ni 掺杂 WO₃ 气体传感器** 的机理研究。这是一个典型的金属氧化物半导体（MOS）气敏材料课题。你想用第一性原理（DFT）计算，从电子结构层面解释三个实验现象。

### 1.2 三个核心科学问题

这份需求文档要回答三个问题：

| 问题 | 一句话概括 | 需要的关键计算 |
|------|-----------|---------------|
| **问题 1：反型层（Inversion Layer）** | 为什么材料在空气里是 p 型，在 N₂ 里是 n 型？ | 平面平均静电势（算功函数）+ 差分电荷密度 + Bader 电荷 |
| **问题 2：W⁶⁺ 还原与电阻增加** | Ni 掺杂后 W 为什么被还原？电阻为什么升高？ | 自旋密度 + PDOS + Bader 电荷 |
| **问题 3：加 PdO 后基线电阻进一步增加** | 为什么 PdO/Ni-WO₃ 界面让电阻更大、且仍是 n 型？ | Bader 电荷 + 差分电荷密度 + 平面平均静电势 |

### 1.3 四个计算模型

| 模型 | 环境 | 计算内容 |
|------|------|---------|
| **模型 1** | N₂ 环境 WO₃（本征） | 结构优化 + PDOS + 自旋密度 + 平面平均静电势 |
| **模型 2** | N₂ 环境 Ni-WO₃ | 结构优化 + PDOS + 自旋密度 + 平面平均静电势 + Bader 电荷 |
| **模型 3** | O₂ 环境 Ni-WO₃ | 结构优化 + PDOS + 差分电荷密度 + 平面平均静电势 + Bader 电荷 |
| **模型 4** | O₂ 环境 PdO/Ni-WO₃ | 结构优化 + PDOS + 差分电荷密度 + 平面平均静电势 + Bader 电荷 |

**关键理解**：N₂ 环境 = 无氧吸附（本征/还原态），O₂ 环境 = 有氧吸附（空气/氧化态）。这是对比的核心：同一材料，有氧和无氧的电子结构差异，就是气敏机理的来源。

### 3.1 你需要先告诉 Skill 你的虚拟机配置

Skill 需要这些硬件信息（对应你需求里的第 1 条）：

| 硬件参数 | 示例值（假设） | 说明 |
|---------|--------------|------|
| 内存 | 128 GB | 分配给虚拟机的总内存 |
| CPU 型号 | Intel Xeon Gold 6338 | 2.0 GHz 基准频率，32 核 |
| CPU 数量 | 2 颗 | 双路 |
| 每颗 CPU 核心数 | 32 核 | 共 64 物理核 |
| 逻辑线程数 | 128 线程 | 若开超线程 |

### 3.2 Skill 给出的资源调度建议

Skill 会根据 `resource-scheduling.md` 的规则，输出类似这样的建议：

```
【资源调度建议】
- 总物理核心：64 核
- 本体系规模：8~32 原子（WO₃ 单胞 32 原子；超胞更多）
- 建议并行设置：
  · OMP = 2（每 MPI 进程配 2 个 OpenMP 线程）
  · NP = 64 / 2 = 32 个 MPI 进程
  · NCORE = 2（与 OMP 一致）
  · KPAR = 1（k 点少时先不开 k 点并行）
- 内存估算：
  · 单进程内存 ≈ 原子数 × 0.02~0.05 GB ≈ 0.6~1.6 GB
  · 总需求 ≈ 32 × 1.6 = 51 GB < 128 × 0.8 = 102 GB ✓ 安全
- 结论：内存充足，可放心用满 64 核。
```

**小白要点**：这一步的目的，是让你**别把机器跑崩、别浪费核**。核心是两条铁律：
1. `NP × 单进程内存 < 总内存 × 0.8`（留 20% 余量）
2. 先用推荐配置跑，再用预计算实测微调

## 四、第二步：生成输入文件（能力 2 前半部分）

### 4.1 四个输入文件是什么（写给小白）

VASP 每次计算必须 4 个文件齐全：

| 文件 | 作用 | 小白类比 |
|------|------|---------|
| **INCAR** | 告诉 VASP"算什么、怎么算" | 作业要求书 |
| **POSCAR** | 原子的位置和晶格 | 建筑图纸 |
| **POTCAR** | 每种元素的赝势（原子的"替身"） | 建材清单 |
| **KPOINTS** | 采样点密度 | 采样精度设置 |

### 4.2 用 Skill 的脚本生成

Skill 内置 `generate_inputs.py`，你可以这样调用（以模型 1：本征 WO₃ 为例）：

```bash
python scripts/generate_inputs.py \
  --task relax \
  --elements "W O" \
  --counts "8 24" \
  --lattice "7.304 0 0; 0 7.536 0; 0 0 7.691" \
  --scale 1.0 \
  --positions "..." \
  --kmesh "4 4 4" \
  --encut 520 \
  --outdir ./model1_N2_WO3
```

**重要提示**：WO₃ 是单斜相（P2₁/n），不是立方。所以 `--lattice` 里要包含 β 角（即 a、b、c 三轴不正交）。如果 POSCAR 坐标自己写，晶格矩阵要体现 β≈90.85°。

### 4.3 关键 INCAR 参数说明（以结构优化为例）

Skill 生成的 INCAR 大致如下，每个参数的含义 Skill 都会解释：

```bash
# INCAR - 结构优化（模型1 本征WO3）
SYSTEM = WO3_relax
ENCUT  = 520          # 截断能，≥ POTCAR ENMAX 的 1.3 倍
ISMEAR = 0            # 半导体用 0（Gaussian smearing）
SIGMA  = 0.05
ISIF   = 3            # 优化晶格+原子位置（要晶格常数就开 3）
IBRION = 2            # 共轭梯度优化
NSW    = 100          # 最大离子步数
EDIFF  = 1E-5         # 电子收敛标准
EDIFFG = -0.02        # 力收敛标准（负值=按力判断，eV/Å）
PREC   = Accurate
LREAL  = .FALSE.
NPAR   = 4            # 并行参数
```

**小白要点**：这里每个参数都是"正确计算"的关键。Skill 会解释为什么这样设，但你只要记住几个最容易错的地方（见第 11 节避坑）。

### 4.4 四个模型的 INCAR 差异

| 参数 | 模型 1/2（结构优化） | 模型 3/4（结构优化） | PDOS/DOS 步骤 | Bader 步骤 |
|------|-------------------|-------------------|--------------|-----------|
| ISMEAR | 0 | 0 | **-5**（四面体法） | 0 |
| ISIF | 3 | 2（吸附不优化晶格） | 2 | 2 |
| 自旋 | ISPIN=2（Ni 有磁矩） | ISPIN=2 | ISPIN=2 | ISPIN=2 |
| LCHARG | 默认 | 默认 | .TRUE. | **.TRUE.**（Bader 需要电荷密度） |
| LAECHG | 默认 | 默认 | 默认 | **.TRUE.**（输出 AECCAR） |
| k 点 | 4×4×4 | 4×4×4 | **加密**（DOS 要密，如 8×8×8 或更高） | 4×4×4 |

**关键差异点（Skill 会强调）**：
- **Ni 掺杂（模型 2/3/4）必须开自旋**：`ISPIN=2`，因为 Ni 有未成对电子，会贡献磁矩。
- **PDOS 必须换 ISMEAR=-5**：这是 DOS 计算的黄金标准，用 0 或 1 算 DOS 会出错。
- **Bader 电荷必须开 LAECHG**：否则拿不到 AECCAR0/AECCAR2 文件，Bader 分析没法做。
- **吸附模型（3/4）用 ISIF=2**：O₂ 吸附在表面，不能优化晶格（否则真空层会塌掉）。

## 五、第三步：严格校验输入文件（能力 2 后半部分，重中之重）

### 5.1 为什么校验是"最关键的一步"

你的原始需求里特别强调："**输入文件只要动过就都要进行仔细的检查分析**"。这是整个 Skill 的**最高优先级铁律**。原因是：

> VASP 一个参数设错，不会报错，而是**静默地给出错误结果**。小白最容易在这里翻车——算了一周，结果是错的，还不知道错在哪。

### 5.2 Skill 的校验脚本

Skill 内置 `validate_inputs.py`，运行：

```bash
python scripts/validate_inputs.py ./model1_N2_WO3
```

它会自动检查这些项目，并逐项给出 PASS/ERROR/WARNING：

| 校验项 | 检查内容 | 模型 1 结果（预期） |
|--------|---------|-------------------|
| POSCAR 元素顺序 vs POTCAR | 元素一一对应 | PASS（W、O 顺序一致） |
| ENCUT vs ENMAX | ENCUT ≥ 1.3×ENMAX | PASS（520 ≥ 245×1.3） |
| KPOINTS 合理性 | 金属/半导体 k 点密度 | PASS |
| ISMEAR 选择 | 半导体用 0，DOS 用 -5 | 检查是否匹配计算目的 |
| ISPIN 是否开启 | 有磁性元素（Ni）必开 | 模型 2/3/4 必须 PASS |
| EDIFF/EDIFFG | 与计算目的匹配 | PASS |
| 真空层厚度 | 吸附模型需 ≥ 15 Å | 模型 3/4 检查 |
| LAECHG/LCHARG | Bader 步骤需开 | 模型 2/3/4 检查 |

### 5.3 联网核验（能力 2 的联网部分）

对于脚本查不出的"物理合理性"，Skill 会联网核对。你的需求里提到"输入文件可以在特定网址查找对比优化"，Skill 内置了 `online-resources.md` 网址清单：

- **结构核对**：Materials Project（https://materialsproject.org/）、ICSD（https://icsd.products.fiz-karlsruhe.de/）、COD（https://www.crystallography.net/cod/）
- **参数核对**：VASP 官方 wiki（https://www.vasp.at/wiki/）
- **文献值核对**：晶格常数、带隙、功函数等对照文献

**本次案例中 Skill 会联网查到的参考值**（这就是"预估结果"的依据）：

| 物理量 | 文献参考值 | 来源 |
|--------|-----------|------|
| WO₃ 单斜晶格 | a=7.304~7.329 Å, b=7.323~7.536 Å, c=7.556~7.691 Å, β≈90.85~91.83° | 多篇 DFT 文献 |
| WO₃ 带隙（PBE） | ~1.3~1.94 eV | PBE 计算值 |
| WO₃ 带隙（实验） | 2.6~3.3 eV | 实验值 |
| m-WO₃(001) 功函数 | ~5.53 eV | DFT 计算值 |
| O₂ 吸附电荷转移 | 完美表面 ~0.01 e；活性/缺陷表面 ~0.64~0.7 e | DFT 文献 |

**⚠️ 遇到抓取不到的网址怎么办？**

这是 Skill 的一条**铁律**：VASP 官方 wiki 等网站有反爬机制，程序抓取会返回 403，但浏览器能正常打开。此时 Skill 会**停下来，告诉你去哪里手动查、怎么查、带什么信息回来**，绝不瞎猜。例如：

> "我需要确认 ENCUT 的默认值，但 VASP wiki 抓取不到。请你在浏览器打开 https://www.vasp.at/wiki/index.php/ENCUT ，按 Ctrl+F 搜索 'Default'，把那一行复制给我。"

## 六、第四步：估算计算耗时（能力 3）

### 6.1 用 Skill 的脚本粗估

```bash
python scripts/estimate_time.py \
  --natoms 32 --nkpoints 64 --encut 520 \
  --task relax --nionic 50 --cores 64
```

输出类似：

```
【耗时估算】
- 单电子步耗时（经验估算）：约 X 秒
- 预计总电子步数：50 离子步 × 40 电子步 = 2000 步
- 预计总耗时：约 4~6 小时（粗估）
```

### 6.2 预计算实测校准（更准的方法）

粗估只是量级参考，真正靠谱的是**预计算实测校准**。这正是你需求里第 3、4 条的联动设计：

```bash
python scripts/estimate_time.py \
  --natoms 32 --nkpoints 64 --encut 520 --task relax --nionic 50 --cores 64 \
  --measured-scf-time 1.2 --measured-encut 400 --measured-nk 8 --measured-natoms 32
```

> 先用一次低 ENCUT（400）、低 k 点（8）的预计算，实测单步耗时 1.2 秒，Skill 会据此**放大到正式计算规模**，给出更准的总耗时。

**小白要点**：耗时估算的意义是**心里有数、安排机时**，不是精确到分钟。经验上，32 原子体系结构优化，64 核跑，通常几小时量级；加 Ni 掺杂、加真空层的吸附模型，时间会翻几倍。

## 七、第五步：预计算（试算）（能力 4）

### 7.1 什么是预计算，为什么要做

预计算就是**用"缩水版"参数先跑一次，几秒到几分钟出结果**，用来：

1. **验证输入文件没低级错误**（一跑就崩 = 有错）
2. **看能量/力趋势是否正常**（能量该降不该升，力该减不该增）
3. **实测单步耗时**（反哺第 6 步的耗时估算）
4. **反推正式结果趋势**（预计算收敛方向对，正式计算基本稳）

### 7.2 怎么做预计算

Skill 会建议你改几个参数让计算"特别快"：

| 参数 | 正式计算 | 预计算 | 说明 |
|------|---------|--------|------|
| ENCUT | 520 | 400 | 降低截断能 |
| k 点 | 4×4×4 | 1×1×1 或 2×2×2 | Γ 点或极疏网格 |
| NSW | 100 | 10 | 只跑 10 步看趋势 |
| EDIFF | 1E-5 | 1E-4 | 放松收敛 |

### 7.3 预计算结果怎么判读（以模型 1 为例）

Skill 会帮你分析预计算的输出：

```
【预计算结果分析】
- 第 1 步：F = -53.21 eV/原子 (初始力较大，正常)
- 第 5 步：F = -1.82 eV/原子 (力快速下降，优化方向正确 ✓)
- 第 10 步：F = -0.35 eV/原子 (仍在下降，趋势良好 ✓)
- 结论：结构在朝稳定方向弛豫，正式计算可以放心继续。
- 实测单步耗时：1.2 秒（据此校准正式计算总时长）
```

**小白要点**：预计算就像"炒菜前先尝一口调料"——确认方向对了再下锅，避免浪费几个小时的正式计算。

## 八、第六步：正式计算与实时监控（能力 5）

### 8.1 提交正式计算

预计算确认无误后，恢复正式参数（ENCUT=520、k=4×4×4、NSW=100），提交计算。Skill 是"纯生成+指导型"，**不会替你登录虚拟机**，而是给你提交命令，你自己复制去跑：

```bash
mpirun -np 32 vasp_std > vasp.log 2>&1 &
```

### 8.2 实时监控 → CSV

计算跑起来后，Skill 用 `monitor_to_csv.py` 解析运行日志，把进度整理成 CSV：

```bash
python scripts/monitor_to_csv.py --oszicar ./OSZICAR --out ./monitor.csv
```

生成的 CSV 长这样（列：`step_type, step_index, scf_iteration, energy, free_energy, dE, elapsed_time, note`）：

| step_type | step_index | scf_iteration | energy | free_energy | dE | elapsed_time | note |
|-----------|-----------|---------------|--------|-------------|-----|--------------|------|
| ion | 1 | 8 | -348.21 | -348.21 | -0.102 | 45.2 | 离子步1 |
| ion | 2 | 7 | -348.35 | -348.35 | -0.081 | 88.7 | 离子步2 |
| ... | ... | ... | ... | ... | ... | ... | ... |

**小白要点**：看 CSV 就能知道：
- `dE` 越来越小 = 在收敛
- `energy` 趋于平稳 = 快收敛了
- `scf_iteration` 突然变大 = 可能卡住，要留意

## 九、第七步：结果分析与报告（能力 6）

这是把"一堆数字"变成"科学结论"的关键一步。Skill 会：

1. **判断是否收敛**：力是否降到 EDIFFG 以下、能量是否平稳
2. **判断物理合理性**：能量量级、键长、带隙是否符合文献
3. **对照文献核验**：带隙、晶格常数、功函数和文献值比对
4. **输出完整 Markdown 报告**

### 9.1 收敛判断（Skill 的自动检查）

```
【收敛性检查】
- 力收敛：最后一个离子步 F < 0.02 eV/Å ✓（已收敛）
- 能量收敛：最后 5 步能量变化 < 1 meV ✓
- 结论：结构优化已收敛，可以进入性质计算。
```

### 9.2 物理合理性判断（Skill 的判据）

Skill 会检查这些物理量是否在合理范围：

| 检查项 | 合理范围 | 你的模型预期 |
|--------|---------|-------------|
| WO₃ 晶格常数 | a≈7.3, b≈7.5, c≈7.7 Å | 优化后应接近 |
| WO₃ 带隙（PBE） | 1.3~1.9 eV | 模型 1 应有明显带隙 |
| W-O 键长 | ~1.8~2.0 Å | 合理 |
| 功函数 | 4.9~6.8 eV | 模型间对比看变化 |

**重要提示（Skill 会说明）**：PBE 泛函**系统性低估带隙约 30%**。所以你算出的带隙比实验值（2.6~3.3 eV）小是**正常的、正确的**，不是算错了。报告里要如实说明这一点。

## 十、第八步：回答三个核心科学问题（报告的核心内容）

这是整个案例的**最终目的**。下面我结合文献预估的结果，演示每个模型会"算出什么"、以及"怎么用它回答科学问题"。

### 10.1 模型 1（N₂ 环境本征 WO₃）—— 建立基线

**预期结果（基于文献）**：
- 结构优化后晶格常数收敛到 a≈7.31, b≈7.52, c≈7.69 Å（接近实验值）
- 带隙约 1.3~1.9 eV（PBE），导带底由 W 5d 主导，价带顶由 O 2p 主导
- PDOS 显示：费米能级（0 eV）在带隙中，靠近导带底 → **本征 n 型**

**判读**：这是"干净"的参照系。本征 WO₃ 是 n 型半导体，费米能级靠近导带。

### 10.2 模型 2（N₂ 环境 Ni-WO₃）—— 回答问题 2 的"W⁶⁺ 还原"

**预期结果（基于文献 Ni 掺杂效应）**：
- Ni 取代 W 位后，**自旋密度图**显示 Ni 周围出现局域的自旋极化（Ni 有未成对 d 电子）
- **PDOS**：Ni 3d 态在带隙中引入杂质能级；部分 W 5d 轨道出现未成对电子 → **W⁵⁺ 信号**
- **Bader 电荷**：Ni 掺杂后体系获得电子（Ni 价比 W⁶⁺ 低，替代后整体电子过剩）

**这是回答"W⁶⁺ 还原"的关键证据链**：
```
Bader 电荷显示体系得电子 + 自旋密度显示 W 5d 有未成对电子
  → W 从 +6 价被还原到 +5 价（W⁶⁺ → W⁵⁺）
  → 证明了材料在缺氧/N₂ 状态下确实发生了 W⁶⁺ 还原
```

**Bader 电荷的起点/终点设置**（对应你需求文档的"起点 Ni，终点周围 W 和 O"）：
- 起点（失去电子）：Ni 掺杂原子
- 终点（得到电子）：Ni 周围的 W 原子和 O 原子

### 10.3 模型 3（O₂ 环境 Ni-WO₃）—— 回答问题 1（反型层）

**预期结果（基于文献 O₂ 吸附）**：
- O₂ 吸附后，**差分电荷密度**显示电子从表面 W、Ni 大量转移到 O₂ 分子（约 0.64~0.7 e）
- **Bader 电荷**：表面 W、Ni 失电子（起点），O₂ 的两个 O 得电子（终点）
- **平面平均静电势**：出现**巨大的阶跃**，功函数显著升高 → 表面发生极端的"向上能带弯曲"

**这是回答"反型层"的关键证据链**：
```
O₂ 强吸电子（差分电荷 + Bader 电荷清晰可见电子转移到 O）
  → 平面平均静电势出现大阶跃（功函数升高）
  → 表面极端向上能带弯曲
  → 表面空穴浓度 > 电子浓度 → 形成空穴反型层（p 型）
  → 解释了为什么纯/Ni 掺杂样品在空气中表现 p 型
```

**PDOS 的直观判读**（你需求文档里"PDOS 图看 NP 型"这段）：
- N₂ 环境：0 eV 上方是 W 5d 波峰（导带），0 eV 下方是 O 2p 波峰（价带），费米能级在带隙中 → n 型
- O₂ 环境：费米能级（0 eV）**直接切进 O 2p 波峰里** → 空穴浓度远大于电子 → p 型（反型层）

### 10.4 模型 4（O₂ 环境 PdO/Ni-WO₃）—— 回答问题 3（PdO 的作用）

**预期结果（基于文献异质结）**：
- **路径 A（界面转移）**：Bader 电荷 + 差分电荷密度显示电子从 Ni-WO₃ 侧的 W、Ni 转移到 PdO 侧的 Pd → **PdO 抢走了 WO₃ 的电子**
- **路径 B（表面转移）**：PdO 表面催化 O₂ 吸附，电子从 Pd 转移到 O₂ 的两个 O
- **平面平均静电势**：界面处出现**极大的内建电场势垒**

**这是回答"基线电阻进一步增加且仍 n 型"的关键证据链**：
```
PdO 与 Ni-WO₃ 形成 p-n 异质结
  → PdO 进一步抽干表面电子（Bader + 差分电荷证明）
  → 界面处极大内建电场势垒（静电势证明）
  → 势垒耗尽表面电子，抑制空穴反型层形成
  → 导电网络回归内部电子（n 型）主导
  → 极宽耗尽层 → 极高初始电阻（基线电阻 Ra 变大）
```

### 10.5 三个问题答案汇总表

| 问题 | 答案 | 关键证据 |
|------|------|---------|
| 1. 反型层 | 空气中 O₂ 吸电子导致表面向上弯曲，形成空穴反型层（p 型） | 静电势阶跃 + 差分电荷 + Bader |
| 2. W⁶⁺ 还原 | Ni 掺杂引入过剩电子，W⁶⁺ 被还原为 W⁵⁺，电阻升高 | 自旋密度 + PDOS + Bader |
| 3. PdO 作用 | PdO 形成 p-n 结抽干表面电子，耗尽层加宽，基线电阻增大且仍 n 型 | Bader + 差分电荷 + 静电势 |

## 十一、常见错误与避坑

这是小白最容易翻车的地方，Skill 在校验环节会自动拦截，但你也要心里有数：

| 错误 | 后果 | 如何避免 |
|------|------|---------|
| POTCAR 元素顺序与 POSCAR 不一致 | 直接算错，还不报错 | 校验脚本自动检查 |
| ENCUT 低于 ENMAX | 结果不收敛 | ENCUT ≥ 1.3×ENMAX |
| 有 Ni 却忘开 ISPIN=2 | 磁矩算错，自旋密度无意义 | 磁性元素必开自旋 |
| DOS 计算用 ISMEAR=0 | DOS 形状错误 | DOS 必须用 ISMEAR=-5 |
| Bader 分析忘开 LAECHG | 拿不到电荷文件 | Bader 步骤必开 LAECHG |
| 吸附模型用 ISIF=3 | 真空层塌掉，结构崩 | 吸附用 ISIF=2 |
| 真空层太薄（<15 Å） | 相邻层镜像相互作用污染结果 | 真空层 ≥ 15 Å |

## 十二、一句话总结：小白操作路线图

```
1. 告诉 Skill 你的硬件配置 → 得到资源调度建议
2. 用脚本生成 4 个输入文件 → 得到 INCAR/POSCAR/POTCAR/KPOINTS
3. 跑校验脚本 + 联网核对 → 确认无 ERROR
4. 估算耗时 → 心里有数
5. 跑预计算 → 看趋势对不对、测单步耗时
6. 正式计算 + 监控转 CSV → 看收敛进度
7. 结果分析 → 判断收敛、物理合理性、对照文献
8. 生成报告 → 回答三个科学问题
9. 重复 2~8 步，依次完成 4 个模型（模型1→2→3→4）
```

**核心心法**：**输入文件动过必重查；预计算先行；结果对照文献；结论诚实标注可信度。** 只要守住这四条，不懂 VASP 理论的小白也能一步步做出正确、可信的计算结果。
