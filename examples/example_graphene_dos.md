# 使用案例 2：石墨烯态密度（DOS）计算——单项能力演示

这个案例演示**单项能力**的调用：用户只想要某个具体结果（DOS），以及如何用**输入文件校验**抓出并修复一个典型错误。

## 背景

石墨烯是二维蜂窝结构材料，是零带隙半导体（狄拉克点）。用户想算它的电子态密度（DOS），需要经历"结构优化 → SCF → DOS"三步。本案例聚焦 DOS 这一步，并展示校验能力的价值。

## 场景一：只调"输入文件校验"能力

用户手里已经有一份石墨烯的 DOS 输入文件，但他不确定对不对，于是说：

> 帮我检查一下这个石墨烯 DOS 计算的输入文件有没有错。

Agent 直接调用能力 2 的校验环节，运行 `validate_inputs.py`，并联网核对。

**发现的问题**（典型错误演示）：

```
[ERROR] 元素顺序不一致: POSCAR=['C'] vs POTCAR=['C','C']
         （POTCAR 被错误地 cat 了两遍，导致 4 原子石墨烯赝势重复）
[ERROR] ENCUT=300 低于 POTCAR ENMAX=400
[WARN] ISMEAR=1（金属用），但 DOS 计算建议用 ISMEAR=-5
```

Agent 的修复建议：
1. 重新生成 POTCAR：`cat /path/to/C/POTCAR > POTCAR`（只 cat 一次）
2. 提高 ENCUT 到 520（≥ 1.3 × ENMAX）
3. DOS 计算改 ISMEAR=-5，加 LORBIT=11、ICHARG=11

**修复后重新校验**（铁律：动过必重查）：
```
[PASS] 元素顺序一致
[PASS] ENCUT=520 ≥ 1.3×ENMAX
[PASS] ISMEAR=-5 适合 DOS
结论: 无 ERROR
```

## 场景二：只调"结果分析"能力

用户跑完 DOS 后，把结果发给 Agent 说：

> 帮我看看这个 DOS 结果对不对，符不符合石墨烯的物理特征。

Agent 调用能力 6，做物理合理性判断：

| 检查项 | 判断 |
|--------|------|
| 费米能级处 DOS | 石墨烯应为 0（狄拉克点零带隙），DOS 在 E_F 处接近 0 → 合理 |
| 价带/导带结构 | 上下近似对称 → 合理 |
| 有无明显带隙 | 若出现 > 0.5 eV 带隙 → 异常，可能是 k 点太疏或 ISMEAR 选错 |

Agent 输出结论：结果符合石墨烯的零带隙半导体特征，可信度中（建议加密 k 点提高 DOS 精度）。

## 场景三：单项调用"耗时估算"

用户问：

> 我这个 100 原子的石墨烯超胞算 DOS，128 核要多久？

Agent 调用能力 3：
```bash
python estimate_time.py --natoms 100 --nkpoints 1000 --encut 520 \
    --task dos --cores 128
```

输出：
```
估算单电子步耗时: 约 0.4 分钟
正式计算总耗时:   约 26.7 小时
置信度: 经验公式粗估（低置信度）
建议: 先做预计算实测校准，或评估是否可降低 k 点密度
```

## 案例要点总结

- **单项能力可独立调用**，Agent 会从提示词识别用户只要校验、只要分析、还是只要估时。
- **校验能力是保命能力**：本案例里元素重复、ENCUT 过低、ISMEAR 选错都是新手高频错误，不查直接跑会浪费大量机时甚至得出错误结论。
- **物理合理性判断**要结合材料特性（石墨烯零带隙），这正是"让不懂理论的小白也能判断对错"的关键。
