# 使用案例 3：多能力组合 + 智能路由演示

这个案例展示 **Agent 如何从提示词自动判断调用哪些能力**，以及一个更复杂的计算场景（多元素、多步流程）如何串联。

## 场景：铁磁体 Fe 的磁矩计算

用户想算体心立方（BCC）铁（Fe）的磁矩。Fe 是铁磁金属，需要设置 MAGMOM，且是金属要用 ISMEAR=1。这是"金属 + 磁性"的进阶案例，涉及多个能力组合。

## 用户的第一句话

> 帮我算 BCC 铁的自发磁矩，我机器是 128 GB 内存、4 颗 16 核 CPU。另外我担心跑太久，先帮我估个时间。

Agent 的路由分析（能力 7）：

| 用户信号 | 识别到的能力 |
|---------|-------------|
| "机器是 128GB、4颗16核" | 能力 1 资源调度 |
| "算 BCC 铁的磁矩" | 能力 2 生成输入文件 |
| "担心跑太久，估个时间" | 能力 3 耗时估算 |

Agent 依次执行这三个能力，并主动提示"建议先做预计算（能力 4）校准耗时"。

## Agent 的输出

### 能力 1：资源调度
```
总核心数 = 4 × 16 = 64
建议 NP=32, OMP=2
INCAR: KPAR=4（Fe 金属 k 点密，适合 k 点并行）
内存：Fe 原胞很小，64 核 128 GB 内存非常充足
```

### 能力 2：生成 + 校验输入文件

**POSCAR**（BCC Fe，2 原子原胞）：
```
BCC Fe
2.8665
-0.5 0.5 0.5
0.5 -0.5 0.5
0.5 0.5 -0.5
Fe
2
Direct
0.0 0.0 0.0
0.5 0.5 0.5
```

**INCAR**（关键：金属 + 磁性）：
```
SYSTEM = BCC Fe
ENCUT = 520
PREC = Accurate
EDIFF = 1E-6
IBRION = -1
NSW = 0
ISMEAR = 1          ← 金属用 MP 展宽
SIGMA = 0.2
MAGMOM = 2*2.3      ← 初始磁矩（每原子 2.3 μB）
ISPIN = 2           ← 自旋极化
LORBIT = 11
```

**校验**：
```
[PASS] 元素顺序一致
[PASS] ENCUT=520 ≥ 1.3×ENMAX
[PASS] ISPIN=2 自旋极化已开启（磁性计算必需）
[PASS] MAGMOM 已设置，原子数匹配
[WARN] ISMEAR=1 适合金属，正确
```

### 能力 3：耗时估算
```
体系：2 原子，8×8×8=64 k点，单点
经验粗估：几分钟级
置信度：低，建议预计算校准
```

## 用户接着追问（触发预计算）

> 先预计算一下，看看磁矩大概会是多少。

Agent 调用能力 4：
- 降级：ENCUT 降到 400，k 点降到 4×4×4，EDIFF 放宽到 1E-4
- 试算后反馈：
```
[预计算结论]
- 实际耗时：20 秒
- 磁矩趋势：约 2.2 μB/原子（接近实验值 2.22 μB！）
- 符合预期：是，BCC Fe 铁磁磁矩约 2.2 μB
- 校准耗时：正式单点预计 ~2 分钟
- 建议：正式计算保持 ENCUT=520、8×8×8，可精确得到磁矩
```

## 用户跑完正式计算（触发监控 + 报告）

> 跑完了，帮我分析结果出报告。

Agent 调用能力 5 + 6：
1. `monitor_to_csv.py` 整理日志为 `fe_monitor.csv`
2. `analyze_results.py` 提取磁矩
3. 生成报告：

```markdown
# VASP 计算报告：BCC Fe 自发磁矩

## 4. 结果数据
- 总磁矩：4.4 μB（2 原子，即 2.2 μB/原子）
- 实验值：2.22 μB/原子，误差 < 1%

## 5. 物理合理性分析
- 磁矩 2.2 μB 符合 Fe 铁磁实验值：合理
- 能量量级符合 BCC Fe：合理
- 金属性（ISMEAR=1）处理正确

## 6. 结论
- 满足需求：是
- 可信度：高（预计算趋势 + 正式结果 + 实验值三方吻合）
```

## 案例要点总结

1. **智能路由**：用户一句话里可以同时包含多个能力信号，Agent 逐一提炼。
2. **预计算的价值**：磁矩这种物理量，预计算就能看出"大约 2.2 μB"的趋势，让用户在正式算之前就有底。
3. **组合调用**：这个案例自然串联了 1→2→3→4→5→6 全部能力，展示了完整闭环。
4. **物理合理性对照**：磁矩、金属性、能量量级都有明确的实验/理论参照，小白也能判断"对不对"。
