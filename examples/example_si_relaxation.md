# 使用案例 1：硅（Si）晶格常数优化——完整流程

这是最经典的入门案例：算单质硅的晶格常数。适合第一次用这个 Skill 的新手，走完所有 6 个能力。

## 背景

硅是半导体，金刚石结构（FCC + 两原子基元）。实验晶格常数约 5.43 Å。我们要用 VASP 做结构优化，得到理论晶格常数，并和实验值对比。

## 第一步：告诉 Agent 你的需求（大白话）

你可以直接说：

> 我想算单质硅的晶格常数。我的机器是 64 GB 内存、2 颗 8 核的 CPU（总共 16 核）。帮我从头到尾跑一遍。

Agent 会自动路由：先做资源调度（能力 1），再生成输入文件（能力 2），然后估算耗时（能力 3）、做预计算（能力 4），最后给你正式计算的建议和结果分析方法（能力 5、6）。

## 第二步：Agent 输出（资源调度，能力 1）

Agent 根据"64 GB 内存、16 核"给出：

```
[资源调度]
- 总核心数 = 2 × 8 = 16
- 建议 MPI 进程数 NP = 8，OpenMP 线程 OMP = 2
- INCAR 并行参数：NCORE = 4, KPAR = 1（Si 原胞 k 点不多）
- 可执行文件：vasp_std
- 内存：Si 原胞（8 原子）很小，单进程 < 1 GB，16 核 64 GB 内存绰绰有余
- 启动命令：mpirun -np 8 vasp_std
```

## 第三步：Agent 生成输入文件（能力 2）

Agent 生成四个输入文件，并用 `validate_inputs.py` 校验。

**POSCAR**（金刚石结构的 Si，8 原子原胞）：
```

Si
2

0.25000000 0.25000000 0.25000000
```

**POTCAR**：`cat /path/to/pot/Si/POTCAR > POTCAR`（元素顺序 Si，与 POSCAR 一致）

**KPOINTS**（半导体，中等网格）：
```
Automatic mesh
0
Monkhorst-Pack
8 8 8
0 0 0
```

**INCAR**（结构优化）：
```
SYSTEM = Si
ENCUT = 520
PREC = Accurate
EDIFF = 1E-6
EDIFFG = -0.01
IBRION = 2
ISIF = 3
NSW = 100
ISMEAR = 0

```

**校验结果**（Agent 运行校验脚本）：
```

[PASS] ENCUT=520 ≥ 1.3×ENMAX
[PASS] ISIF/IBRION 组合合理
```

## 第四步：耗时估算（能力 3）

```
[耗时估算]
- 体系：8 原子，8×8×8=64 k点，ENCUT=520
- 经验粗估：单点约几分钟，结构优化约 1 小时内
- 置信度：低（未校准）
- 建议：先做预计算校准
```

## 第五步：预计算（能力 4）

Agent 建议把参数降级跑一次快试算：
- ENCUT 降到 400，k 点降到 4×4×4，EDIFF 放宽到 1E-4，NSW 只跑 5 步

试算结果反馈：
```
[预计算结论]
- 实际耗时：30 秒
- 能量趋势：从 -10.8 eV 降至 -10.9 eV，正常收敛
- 初始最大力：0.3 eV/Å，结构离平衡较近，正式优化预计 ~15 个离子步
- 单电子步实测耗时：0.5 秒 → 校准后正式计算预计 ~10 分钟
- 符合预期：是（能量量级符合 Si）
- 建议：ENCUT 保持 520，NSW 设为 50 足够
```

## 第六步：正式计算 + 监控（能力 5）

用户跑正式计算，Agent 用 `monitor_to_csv.py` 把 OSZICAR 整理成 CSV：

```bash
python monitor_to_csv.py --oszicar OSZICAR --out si_monitor.csv
```


## 第七步：结果分析 + 报告（能力 6）

Agent 运行 `analyze_results.py` 并生成报告：

```markdown
# VASP 计算报告：Si 晶格常数优化

## 1. 计算概述
- 目的：求 Si 理论晶格常数
- 体系：金刚石结构 Si，8 原子原胞

## 2. 计算设置
- 16 核并行，ENCUT=520，8×8×8 k点，PBE 泛函

## 3. 收敛情况
- 电子收敛：是
- 离子收敛：是（15 步收敛）

## 4. 结果数据
- 优化后晶格常数：5.47 Å
- 实验值：5.43 Å，误差 0.7%（PBE 系统误差范围内）

## 5. 物理合理性分析
- 晶格常数误差 0.7%：合理（PBE 通常高估 1~2%）
- 能量量级：每原子约 -5.4 eV：合理

## 6. 结论
- 满足需求：是
- 可信度：高

## 7. 附录
- 监控数据：si_monitor.csv
```

## 案例要点总结

这个案例演示了完整闭环：**资源调度 → 生成 → 校验 → 估算 → 预计算校准 → 监控 → 报告**。新手照做即可得到可信结果，关键是每一步 Agent 都给了"为什么"和"对不对"的判断。
